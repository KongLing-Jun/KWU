# v1.1.2

## 新增

- 会话与工作区列表新增“查看更多”，默认保持列表简洁，同时显示剩余数量并确保当前会话始终可见。
- 专家目录新增热门、最新排序，云端专家和专家团队的收藏状态可随账户同步。
- 云端能力支持图片、音频和视频内容理解，并在视频生成过程中显示任务进度。

## 优化

- 统一模型广场与会话模型选择器的数据和排序状态，切换账户、套餐或当前模型后展示更稳定一致。
- 优化专家、项目和模型卡片的排版、悬浮反馈及筛选控件，降低低性能设备上的重绘开销。
- 调整首页场景选择、侧边栏品牌入口、分区标题和账户入口的视觉层级，改善窄窗口下的布局与操作体验。

## 修复

- 修复专家建议插入输入框后可能重复注入，以及切换会话时草稿内容可能重复出现的问题。
- 修复未发送的空白会话显示在列表中，以及刷新后列表折叠状态和当前会话定位异常的问题。
- 修复新建会话与重命名交互不一致、部分卡片悬浮色块叠加及主题色显示不正确的问题。
- 修复桌面发布清单可能遗漏版本说明的问题，确保应用内更新能够获取对应更新日志。
