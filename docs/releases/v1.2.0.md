# v1.2.0

## 新增

- 新增自动化工作区，可按间隔、每日、每周、每月等周期创建任务，配置全局或项目作用域、模型、权限等级和生效时间，并查看近期运行记录。
- 自动化任务支持同时选择多个连接器与通知目标；单个目标投递失败时，不再阻塞其他目标继续投递。
- Pro 套餐的自动化任务数量调整为不限。
- 新增云项目工作区，可集中管理项目指令、能力、资产、动态和自动化运行，并从项目上下文直接发起任务。
- 在已开放成员协作的 Cloud 环境中，项目所有者可创建和撤销 24 小时有效的邀请链接、管理项目成员，受邀用户可通过链接加入项目。
- 项目事项支持表格、看板、列表、甘特图和日历五种视图，可维护状态、优先级、负责人、开始日期和截止日期。
- 新增公共技能库，支持按分类和关键词浏览、连续加载、安装技能，并统一管理本地已安装技能。
- 扩展连接器目录与授权流程，支持飞书、腾讯文档、GitHub、乐享知识库、Canva 可画和微云等服务，并允许为不同项目独立启用连接器。
- 输入区新增工具权限和推理强度控制，可为不同会话保留模型、强度与审批方式。

## 优化

- 优化项目创建、事项编辑、资产目录、动态留言和能力配置流程，操作结果会刷新为云端最新状态，并在冲突或失败时保留未提交内容。
- 优化专家与专家团队的历史恢复、任务状态和产物交付，补充中文运行状态，并让生成文件更容易从回复中打开。
- 调整账户订阅方案和模型广场的信息层级，简化模型卡片、价格说明和名称搜索。
- 优化创建页、场景选择、侧边栏和弹层在小尺寸窗口下的布局与操作体验。
- 更新自动化模板，突出办公软件技巧、内容处理和周期性工作等常用场景。

## 修复

- 修复自动化任务长期生效日期显示不正确、下次运行时间序列化异常、并发编辑版本冲突及多目标通知失败相互影响的问题。
- 修复云项目会话归属、项目自动化隔离、本地目录同步、能力目录加载及长选项列表操作不稳定的问题。
- 修复切换或新建会话时可能闪现旧历史、草稿或会话配置串用，以及完成态持续显示加载中的问题。
- 修复专家会话返回时滚动位置漂移、历史专家团队绑定丢失、首次进入专家页样式闪烁及长对话跟随不稳定的问题。
- 修复结构化产物、无路径产物和生成文件可能未出现在最终回复中，或隐藏工具文件被误认为交付物的问题。
- 修复连接器授权轮询、Token 刷新、任务切换与重启恢复过程中状态不同步的问题。
- 修复模型目录首次加载、账户刷新、模型名称搜索、长名称与分层价格卡片显示异常的问题。
- 修复媒体理解工具在部分模型接口下的参数模式兼容问题。
