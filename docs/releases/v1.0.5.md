# v1.0.5

## 更新内容

- 输入框支持搜索和选择多个技能与 MCP 连接器；选择会跟随当前对话，连接失败时也会保留已经输入的内容。
- 支持同步云端专家与专家团，并可通过模型生成图片和视频，生成结果会直接显示在会话中。
- 优化模型选择与模型身份显示，减少目录加载、切换确认和重新打开会话时的闪烁及状态不一致。
- 优化已有会话和新建会话的加载体验，避免切换过程中短暂显示其他会话内容或错误场景。
- 飞书发起的会话支持自动显示手机侧的新消息和 Agent 回复，并修复交互卡片权限误判。
- 自动化任务首次点击“立即执行”后，运行记录会及时出现，无需再次点击刷新。
- 更新账户中心界面，统一账户头像，并更清晰地展示身份、余额、订阅和同步状态。
