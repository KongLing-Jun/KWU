# v1.3.0

## 新增

- 账户中心新增积分与套餐页面，可查看套餐积分和充值积分，并支持按固定金额或自定义金额充值；模型生态展示也已整合到账户中心，可按供应商浏览可用模型。
- 云项目工作区扩展成员协作、能力配置、项目资产、动态留言和事项管理能力；新建项目时可同时选择多个专家或技能，并可在项目上下文中继续处理任务。
- 自动化任务支持关联自有或已加入的云项目，并可选择用户专家或专家团队作为执行能力；任务保存时会固定当时选择的模型，避免后续因默认模型变化而改变执行路由。
- 新增实验性的跨境电商研究工作区，可生成带图表、详情和多来源引用的持久化智能看板，并使用公开商品目录数据辅助选品研究。该入口默认关闭，可在“设置 > 实验性功能”中启用。
- 新增本地故障日志，在不保存用户内容、凭据和完整路径的前提下记录结构化错误，帮助定位崩溃、认证和工作区操作异常。

## 优化

- 优化项目事项的表格、看板、甘特图和日历交互，统一完整时间显示，改进多事项展开、今日定位、资产操作、留言附件和共享项目导航。
- 优化连接器的项目配置、全局启用和连接状态展示；临时失败可安全重试，需要重新授权时会给出更明确的处理提示。
- 优化专家创建流程，支持自定义分类和标签；未填写预设问题时会自动生成建议问题，并完善专家及专家团队元数据同步。
- 自动化列表会优先显示已启用任务，并按下次运行时间排序；账户退出、心跳周期选择和积分结算状态的反馈更加清晰。
- 项目树新增更稳定的运行、未读和错误状态提示，悬浮操作不再挤压或遮挡运行标记。
- 桌面端默认主题调整为浅色；已明确选择自动、浅色或深色主题的用户设置保持不变。

## 修复

- 修复登录、注册、账号切换和 Token 刷新期间可能出现的认证竞态、账户状态串用，以及登录后项目目录和专家入口未及时刷新的问题。
- 修复会话终态可能重复显示、旧事件污染新回合、侧栏在任务结束后仍显示运行中，以及项目标题在瞬时读取失败后退化的问题。
- 修复远程 MCP 连接器在 OAuth 元数据地址不可用时无法回退、平台无关连接器安装受限，以及凭据读取、刷新和重授权状态不稳定的问题。
- 修复项目工作区中的事项附件、详情、甘特图、对话草稿、留言下载、资产刷新、账号隔离和弹窗操作问题。
- 修复模型与积分余额来源不一致、自动化任务执行模型可能随默认值变化，以及部分 Composer 不可发送状态样式不统一的问题。

## 注意事项

- 本版本移除了旧版学习型用户画像、桌面 Hooks 和手动代理设置入口；网络请求仍继续使用系统及运行环境的网络配置。
- 移除了不可用的关闭标签页快捷键；标签页仍可通过界面中的关闭按钮操作。
