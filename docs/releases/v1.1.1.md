# v1.1.1

## 优化

- 统一工具调用名称、上下文 token、模型广场及账户注册相关中文文案，信息表达更加清晰。
- 提升启动页、侧边栏、项目列表和模式选项等界面文字的对比度与可读性。

## 修复

- 修复 Windows 安装时应用仍在运行可能造成文件占用的问题；安装器现在会提示完全退出应用后重试，取消操作会直接退出且不会修改现有文件。
- 修复 Windows 卸载过程中短暂弹出命令行窗口的问题。
- 修复专家能力菜单点击后意外关闭，以及小尺寸窗口下部分操作项无法查看的问题。
- 修复部分 Windows ARM64 设备上消息通道卡片滚动或悬停时出现闪烁、色块的问题。
- 修复项目页和工作区在窄窗口下内容无法完整滚动或显示的问题。
- 修复模型服务异常提示不够明确，以及自动化任务或 Bot 可能重复显示失败消息的问题。
