# v1.4.0

## 新增

- 新增资料库，集中查看不同会话交付的文件，支持文件类型筛选和搜索，可直接打开文件或返回来源会话。
- 新增统一文件交付卡片，明确交付的文件可登记到资料库，并与工作区中的引用文件区分，便于查找和继续使用。
- Windows 版增加 Python 运行环境兜底，优先复用兼容的系统 Python，减少因本机缺少可用 Python 导致的受支持脚本任务执行失败。

## 优化

- 改进会话过程保存与恢复，重新打开会话时可恢复已记录的过程；切换任务时更完整地保留对话内容与滚动位置。
- 更早显示工具准备状态；任务执行时展开过程，完成后自动收起，便于查看最终结果。
- 改进图片、视频生成及历史媒体展示，优化本地媒体和 Markdown 预览，并完善媒体工具费用的积分结算。
- 优化云项目会话的标题、排序和工作区归属；项目输入区的工具权限选择更加清晰，新会话可沿用上次选择的权限。

## 修复

- 修复启动时云项目尚未加载完成导致到期自动化任务被错误阻止的问题，以及项目选择列表重复、任务工作区归属错误和项目或模板加载相互影响的问题。
- 修复切换模型时可能卡住、会话一直加载，以及模型目录加载不稳定、切换账号后仍显示旧模型目录的问题。
- 修复首次启动任务未及时出现在任务树，以及悬浮、聚焦或打开会话菜单时运行标记消失的问题。
- 修复思考过程显示短暂停顿后集中补齐的问题，使流式内容与任务状态的展示更加连贯。
- 修复资料库在退出账号、切换账号或失去云项目访问权限后仍显示旧范围文件的问题；云项目文件显示正确项目名称，已删除或失去访问权限的云项目不再以本地工作区形式重新出现。
- 修复项目会话首次召唤专家时跳转到新对话，以及部分消息总结操作被拒绝的问题。
