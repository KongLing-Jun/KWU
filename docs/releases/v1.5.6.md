# v1.5.6

## 新增

- 新增资料库，集中查看不同会话交付的文件，支持按文件类型筛选和搜索，可直接打开文件或返回来源会话。
- 新增统一文件交付卡片，交付文件可登记到资料库，便于查找、复用和继续处理。
- Windows 版增加 Python 运行环境兜底，优先复用兼容的系统 Python，减少因缺少可用 Python 导致的脚本任务执行失败。

## 优化

- 优化子专家失败提示，在同一次执行的完整诊断已保留到任务详情时减少重复横幅，仍保留失败次数、原始错误和部分输出。
- 优化自动化编辑器的保存反馈，保存中及时显示状态并避免重复提交；保存失败时保留草稿，必填项或模型不可用时明确提示并定位到对应字段。
- 改进会话过程保存与恢复，重新打开会话时可恢复已记录的执行过程和积分消耗；切换任务时更完整地保留对话内容与滚动位置。
- 项目对话发送后立即显示等待反馈，减少新会话创建和发送过程中的重复加载。
- 更早显示工具准备状态；任务执行时展开过程，完成后自动收起，方便查看最终结果。
- 改进图片、视频生成及历史媒体展示，优化本地媒体和 Markdown 预览，完善媒体工具费用的积分结算。
- 优化云项目会话的标题、排序和工作区归属；统一项目输入区的工具权限选择，新会话可沿用上次选择的权限。
- 完善项目对话失败时的本地诊断信息，便于通过诊断编号定位异常。

## 修复

- 修复桌面端重启后会话记录标识冲突、自动化输出未正确保存，以及继续对话时新回答被合并到上次未完成消息的问题；迟到的历史事件不再覆盖新一轮回答。
- 修复 Windows 退出应用后未完成的自动化任务仍显示运行中的问题，确认原进程已退出后恢复中断状态并保留产物，不会自动重跑旧任务；手动启动被拒绝时明确返回失败。
- 修复其他任务运行期间，自动化编辑器的模型状态在加载中和不可用之间反复切换的问题，减少无关界面刷新引起的重复读取。
- 修复通过 Alt+Tab 返回应用时模型名称和反馈提示短暂丢失的问题；后台刷新期间保留已有展示和错误提示，校验未完成或失败时仍阻止提交。
- 修复自动化任务或模板提交后看似无响应、保存成功反馈被列表刷新延迟的问题；明确区分提交前检查失败、保存结果待确认和任务已保存但模板保存失败等情况。
- 修复未选择的云专家目录加载失败也会阻止自动化任务保存或执行的问题，能力检查只加载任务实际选择的类别，并统一保存前检查与执行时的模型和能力校验。
- 修复打开已有会话时，历史内容先显示、又被加载提示替换的问题；历史同步失败时保留可读内容并支持重试，专家团队布局加载时也更稳定地保留历史内容与阅读位置。
- 修复 Windows 上专家状态文件短暂被占用时读取失败的问题，减少由此产生的对话警告；改进保存失败时的文件保护，避免覆盖原有专家数据。
- 修复普通对话和项目对话中，选择专家团队后在使用前取消，仍残留团队展示或专家上下文的问题；取消后发送消息会等待取消操作成功，同时保留实际使用过的团队记录。
- 修复任务取消或中断后，已产生的模型调用用量未完成积分结算，以及重新打开会话后已结算积分未恢复显示的问题。
- 修复连接器目录尚未就绪时部分能力任务无法提交的问题，改进目录恢复与提交检查。
- 修复启动时云项目尚未加载完成导致到期自动化任务被错误阻止，以及项目列表重复、任务工作区归属错误和项目或模板加载相互影响的问题。
- 修复切换模型时可能卡住、会话一直加载，以及模型目录加载不稳定、切换账号后仍显示旧目录的问题。
- 修复首次启动任务未及时出现在任务树，以及悬浮、聚焦或打开会话菜单时运行标记消失的问题。
- 修复思考过程短暂停顿后集中补齐，以及会话恢复时部分过程展示不完整的问题。
- 修复退出账号、切换账号或失去云项目访问权限后，资料库仍显示旧范围文件的问题；已删除或失去访问权限的云项目不再以本地工作区形式重新出现。
- 修复项目会话首次召唤专家时跳转到新对话，以及部分消息总结操作被拒绝的问题。

## 已知问题

- Windows ARM64 上此前报告的间歇性项目对话失败仍需实机复验，本版本不承诺该问题已完全解决。
- 旧版本中从未保存成功的历史事件无法由本次更新补回。
