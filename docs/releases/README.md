# 桌面版本更新说明

每个 stable 桌面版本在创建 Tag 前，必须随 source commit 提交一份 `vX.Y.Z.md`。例如：

```text
docs/releases/v1.0.11.md
```

文件要求：

- 文件名版本必须与 `desktop-vX.Y.Z` Tag 完全一致。
- UTF-8 Markdown，最大 64 KiB。
- 可以使用标题、段落、列表、粗体、代码和普通链接。
- 一期不允许 HTML 或图片。
- 内容会原样用于 GitHub Release 正文和云平台四条桌面版本记录，不要包含内部密钥、临时链接或仅供开发人员阅读的信息。

建议结构：

```markdown
# v1.0.11

## 新增

- 描述用户可以感知的新能力。

## 修复

- 描述已修复的问题。

## 注意事项

- 仅在确有升级注意事项时保留此小节。
```

Tag 创建后不得再修改同一版本的说明或移动 Tag；需要改动时发布新的 patch 版本。
