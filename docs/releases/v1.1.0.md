# v1.1.0

## 新增

- 账户中心新增“忘记密码”功能，支持通过绑定手机号、滑块验证和短信验证码重置登录密码。
- 新增“帮助与反馈”入口，可提交文字说明及最多 4 张 PNG/JPEG 图片，并在提交成功后显示反馈编号。
- 输入区整合协作模式、专家、技能和连接器入口，选择和管理当前任务所需能力更加集中。

## 优化

- 登录和注册表单增加请求前必填校验，并为常见账户、验证码和密码问题提供更明确的中文提示。
- 优化模型广场的中文展示，统一供应商名称、令牌计费单位和模型限制说明。
- 优化桌面更新机制，按当前平台获取适用版本；主要更新源不可用时可有序切换备用来源。
- 优化更新安装授权提示，补充更清晰的中文错误说明和处理建议。

## 修复

- 修复云端任务结算后账户余额未及时刷新的问题。
- 修复桌面服务短暂断开可能导致页面崩溃的问题；断线期间会显示重连提示，服务恢复后自动重新加载。
- 修复部分更新来源不可用时，已经下载并验证的安装包仍无法继续安装的问题。
- 优化重置密码过程中的验证码、密码格式和服务端错误提示。
