# 界面交互与错误状态

## 1. 连接器入口

WorkBuddy 5.3.5 左侧主导航包含“专家·技能·连接器”。进入后顶部有三个页签：专家、技能、连接器。

连接器页顶部包含：

- 搜索框“搜索连接器”。
- “自定义连接器”按钮。
- 两列连接器卡片。

参考：[连接器市场截图](resources/assets/ui/02-连接器市场.png)。

## 2. 连接器卡片

卡片字段包括：

- 图标。
- 名称。
- 一段业务描述。
- 右侧圆形添加按钮。

截图中可见的卡片包括通达信、腾讯自选股、QQ 邮箱、ima 知识库、乐享知识库、腾讯文档、腾讯会议、企业微信、飞书、钉钉、腾讯问卷、TAPD、CNB 和微云。

搜索功能在 WorkBuddy 5.3.3 更新日志中加入。

## 3. 添加入口

点击卡片右侧“+”后，界面根据连接器配置进入不同流程：

| 配置类型 | 界面行为 |
|---|---|
| 无需用户输入的 MCP | 直接进入连接流程 |
| Token Schema | 打开动态字段表单 |
| MCP OAuth | 打开授权页面并等待回调 |
| server-side | 调用 WorkBuddy 云端授权接口并轮询 |
| CLI | 执行安装、登录和 status 检查 |
| Skill-only | 安装或启用 Skill |

连接器详情展示：

- 名称和描述。
- 当前连接状态。
- 配置或授权入口。
- 连接后的“解绑”。
- 连接后的“去试试”。

## 6. MCP 服务管理

“自定义连接器”打开 MCP 服务管理弹窗，包含：

- “配置 MCP”按钮。
- “MCP Hub”入口。
- Server 搜索框。
- Server 列表和状态。
- 空状态“暂无 MCP 服务器”。

参考：[自定义 MCP 管理截图](resources/assets/ui/03-自定义MCP管理.png)。

本机用户级配置路径为：

```text
C:\Users\<user>\.workbuddy\mcp.json
```

空配置内容为：

```json
{
  "mcpServers": {}
}
```

## 7. 自定义配置校验

配置编辑器执行以下校验和归一化：

- 根对象包含 `mcpServers` 对象。
- 每个 Server 配置是对象。
- 空文本归一化为 `{"mcpServers":{}}`。
- 误写成 `mcpServers.mcpServers` 时自动提升内层对象，外层同名配置优先。
- 运行时有效项具有 `url` 或 `command`。

保存后，服务层执行 JSON parse 和 pretty-print，再由 MCP Runtime 连接有效项。

## 9. Token 表单

Token 型连接器按 `token-schema.json` 渲染：

- 标题和说明。
- 文档链接。
- text 或 password 字段。
- 必填标记。
- placeholder 和帮助文字。

密码字段返回 UI 时不包含原值，只包含是否已经配置。

## 10. CLI 授权界面

静态配置支持以下 UI 交互：

- 打开授权 URL。
- 内嵌二维码弹窗。
- Device Flow verification URI 和 user code。
- 等待 CLI 登录命令退出。
- 轮询 status。
- 展示安装、版本、授权和状态错误。

## 11. 安全中心关联设置

安全中心中可见“内置运行时”，包含 WorkBuddy 随包提供的 Python、Node.js 和 Git Bash。CLI 连接器安装和授权使用这些托管运行时能力。

参考：[安全中心截图](resources/assets/ui/01-安全中心.png)。
