## 4. WorkBuddy 事实边界

WorkBuddy 5.3.5 逆向快照注册 73 个定义，其中摘要包含 15 个 CLI、4 个 SSE、4 个 stdio 和 16 个 Token 配置。分类存在交叠，不能用“有 URL”直接判断可首发。

当前只纳入同时满足官方公开 HTTPS endpoint、Streamable HTTP、无本地环境和可表达认证的连接器。内部/iOA 地址、私有 server-side auth、失效接口和需要本地代理的定义排除。

## 6. 更新规则

- 新第三方事实必须附官方链接、公开 endpoint 或脱敏真实响应。
- “未找到”只能标记为待核实，不能推断厂商没有远程 MCP。
- 用户裁决必须写入本文件和 `09`。
- 历史事实只能标记为 `HISTORICAL/SUPERSEDED`，不得删除以制造一致性。
