# 连接器任务提交记录说明

## 1. 用途

本文件集中记录 Reasonix 连接器任务在各仓库产生的 Git 提交，便于复审、联调、回溯和后续分批开发。

适用仓库包括但不限于：

- `D:\github\Reasonix-worktrees\model-hub`
- `D:\github\Reasonix-Cloud`
- `D:\github\naive-ui-admin`
- 后续明确纳入连接器任务的其他仓库

## 2. 强制记录规则

1. 连接器任务只要在任一仓库创建提交，就必须在本文件追加记录。
2. 每条记录至少包含日期、仓库、分支、完整 commit SHA、提交说明和文件范围。
3. 多仓库提交先分别完成并核对，再集中更新本文件。
4. 本文件必须单独提交，不能与连接器功能代码、跨仓库文档或其他未提交改动混在同一提交中。
5. 记录前后均使用精确文件白名单检查暂存区，不使用 `git add .`、`git add -A` 或 `git commit -a`。
6. 默认只记录已成功创建的本地提交；是否推送必须明确标注。
7. 维护本记录文件产生的提交不再递归追加自身，避免无限记录；其 commit SHA 在任务最终交付说明中报告。
