## 6. P1

### P1-1 模型价格与阶梯边界直接暴露原始数据

**复现**

1. 打开模型市场。
2. 搜索 `claude-sonnet-4-5-20250929`。
3. 可见 `$0.00030000000000000004 / 1K Tokens`、`$0.0006000000000000001 / 1K Tokens` 和 `max_tokens -1`。
4. 右侧浏览器、Chrome、原生 Wails 三端结果一致。

**影响**

模型市场是购买/选择决策入口。浮点尾数降低可信度，`-1` 作为内部无限制哨兵直接展示会被用户理解为负数上限。

**代码证据**

- `desktop/frontend/src/features/model-marketplace/ui/ModelMarketplace.tsx:493-499` 直接渲染 `tier.maxTokens` 和价格。
- `desktop/frontend/src/features/model-marketplace/ui/ModelMarketplace.tsx:592-602` 仅移动小数位，没有按展示精度规范化。
- `desktop/frontend/src/__tests__/model-marketplace.test.tsx:299` 明确把长小数作为期望文本，因此现有测试会锁定错误体验。

**建议的 TDD 红灯**

先将 UI 契约改为：价格移位后去除无意义尾数；`maxTokens === "-1"` 显示“无限制”或不展示边界。让现有长小数断言先失败，再做最小格式化修复。

### P1-2 当前模型状态不能跨客户端实时同步

**复现**

1. 右侧浏览器显示 `qwen3.7-plus` 为当前模型。
2. 同时打开的 Chrome 模型市场把所有模型显示为“选择”。
3. Chrome 完整刷新后才恢复 `qwen3.7-plus` 当前状态。

**影响**

多窗口或浏览器/桌面并用时，用户可能基于陈旧状态重复选择模型，无法确认实际生效配置。

**测试缺口**

现有 `browser-client-sync-contract.test.ts` 覆盖启动/引导契约，没有覆盖“一个客户端改变或刷新模型状态后，其他客户端收到事件并重载”的运行时行为。

**建议的 TDD 红灯**

增加双客户端集成测试：客户端 A 更新/刷新模型状态，客户端 B 不刷新页面也应在事件后更新当前模型标记。

### P1-3 原生窗口关闭后，二次启动未恢复窗口

**复现**

1. `34291`、`5291` 均在监听，但目标进程 `MainWindowHandle=0`，桌面无可定位窗口。
2. 再次启动同一 `kwu-desktop-dev.exe` 后出现第二个无窗口进程，原窗口仍未恢复。
3. 仅在精确终止该项目进程树并按原脚本重启后，窗口恢复。

**影响**

用户可能看到后台仍运行、浏览器服务也正常，但无法重新打开桌面应用，只能完全重启。

**代码证据**

- `desktop/app.go:674` 定义 `showMainWindow`。
- `desktop/app.go:680-681` 二次实例回调调用 `showMainWindow`。

**建议的 TDD 红灯**

补充 Windows 集成测试：关闭/隐藏主窗口后启动第二实例，断言原进程窗口可见且前置，同时断言不会留下第二个无窗口进程。

## 7. P2

### P2-1 新建自动化页面标题显示为“编辑任务”

新建按钮和使用模板都会进入草稿编辑态，但标题显示“编辑任务”。`HeartbeatPanel.tsx:969` 仅根据 `editing` 是否存在选择标题，没有区分新增与已有任务。

建议先补充“新建显示新增任务、编辑已有任务显示编辑任务”的 UI 契约测试。

### P2-2 自动化周期时间输入缺少可访问名称

周期编辑器的 `type="time"` 输入位于 `HeartbeatPanel.tsx:1965-1970`，没有 `label`、`aria-label` 或 `aria-labelledby`。无障碍树只能暴露值，读屏用户无法知道该输入的用途。

建议先添加无障碍查询测试，要求时间输入可通过“执行时间”等稳定名称定位，再补充关联标签。

### P2-3 `runtime:ready` 被持续记录为未知前端消息

Wails 运行日志在浏览器连接或重连时重复出现：

```text
process message error: runtime:ready -> Unknown message from front end: runtime:ready
Unknown message from front end: runtime:ready
```

仓库业务源码中未找到该消息字面量，推测来自 Wails 注入运行时或协议版本边界。当前未观察到功能中断，但持续错误日志会掩盖真实故障。

建议用浏览器连接集成测试捕获运行日志，明确该消息应被识别、忽略或由匹配版本的运行时处理。
