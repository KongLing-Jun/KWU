## 覆盖口径

本轮将测试证据分为三类：

1. **运行时验证**：Chrome 中的真实 React 页面、Wails 桌面窗口可访问性树、项目现有 Playwright 测试。
2. **自动化验证**：129 个前端测试文件、572 个 Go 测试文件、构建、静态检查、race 与依赖审计。
3. **静态链路核对**：React/Wails `App` 方法、后端领域包、JSONL/SQLite 存储职责。

以下流程未产生真实外部副作用，因此不记为通过：

- 真实短信、CAPTCHA、注册、登录和账户切换。
- 真实支付下单、扫码、支付确认、退款或订阅变更。
- QQ、飞书、Lark、微信的真实扫码、联网、消息收发。
- 真实模型供应商调用与扣费。
- 删除数据、覆盖文件、执行自动化任务和向第三方发送内容。

这些链路由现有前后端测试覆盖了状态机与接口契约，但仍需具备测试账号、沙箱渠道和明确副作用授权后才能做真实端到端验收。
