## AUTO-QA-001：星期按钮触发 React 渲染期跨组件更新

- 严重程度：Medium
- 状态：Resolved
- 触发路径：添加任务 → 周期 → 点击任意星期按钮
- 用户影响：当前交互仍能完成，但控制台产生 React 状态更新错误；在并发渲染或后续 React 升级中可能产生不稳定更新。

控制台错误：

```text
Cannot update a component (`TaskEditor`) while rendering a different component (`CycleEditor`).
```

根因证据：

- `desktop/frontend/src/features/automation/heartbeat/HeartbeatPanel.tsx:1597`
- `onDayToggle` 在 `setSelectedDays` 的状态更新函数内部调用父组件的 `setDraft`。
- 对应调用位于 `HeartbeatPanel.tsx:1601`。

修复结果：

- 已把 `next` 的计算和父组件 `setDraft` 调用移出 `setSelectedDays` 状态更新函数。
- 星期按钮仍会同步更新本地选择状态和任务周期，但不再在 `CycleEditor` 渲染期间更新 `TaskEditor`。
- 自动化面板契约测试新增回归约束，防止 `setDraft` 再次嵌套进 `setSelectedDays` 更新函数。
- Wails 页面回归中点击“周一”后 `aria-pressed` 从开启切换为关闭，且控制台没有新增对应 React 错误。

## AUTO-QA-002：未生成会话时“打开对话”按钮没有可访问名称

- 严重程度：Low
- 状态：Resolved
- 触发路径：新建自定义任务但尚未执行
- 用户影响：任务卡片第二个操作按钮处于禁用状态，但没有 `aria-label`，且 `title` 被设置为空字符串；读屏器只能识别为无名称按钮。

根因证据：

- `desktop/frontend/src/features/automation/heartbeat/HeartbeatPanel.tsx:1238`
- 按钮在 `task.topicId` 为空时禁用。
- `HeartbeatPanel.tsx:1248` 同时把 `title` 设置为空字符串，且没有独立 `aria-label`。

修复结果：

- “打开对话”按钮现在始终提供本地化的 `title` 和 `aria-label`。
- `task.topicId` 为空时仍仅通过 `disabled` 表达不可用，不再移除按钮名称。
- 自动化面板契约测试新增回归约束，覆盖禁用状态下的可访问名称。
- Wails 页面新建未运行的临时任务后，按钮保持禁用，同时 `title` 与 `aria-label` 均为“打开对话”；临时任务已删除。
