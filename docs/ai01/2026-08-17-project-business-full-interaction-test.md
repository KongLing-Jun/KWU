## 缺陷复现

### P1 模态弹窗缺少背景语义隔离

1. 打开“项目”页面。
2. 点击“新建云项目”。
3. 保持弹窗打开，定位后台“搜索云项目”。
4. 真实指针点击被遮罩拦截，但直接定位 DOM 的自动化写入仍能命中后台输入。

修复：模态挂载期间对模态分支外的 body 子树设置引用计数式 `inert`，嵌套模态关闭时精确恢复；Vitest 覆盖挂载和恢复。

### P2 优先级筛选中英文不一致

1. 进入项目 > 事项。
2. 打开“筛选事项” > 优先级。
3. 菜单显示 `low / medium / high / urgent`。

修复：抽取统一 label helper，筛选、卡片、详情均显示“低 / 中 / 高 / 紧急”。

### P1 项目会话首轮归属缓存

首次从云项目加号创建会话时，sidecar 已含正确 `project_context.project_id`，但项目树在空 transcript 阶段缓存了“无会话”。首轮完成后 listing 未同步，运行态 session 因而按物理 global topic 显示。修复后 `TurnDone` 同步写入 `Preview/Turns` 并触发树缓存失效。

### P1 删除后的幽灵项目

`ProjectCache.RemoveProject` 在无 detail 时输出 `"details": null`，下一次 Load 按严格 schema 将其隔离；同时 session-only fallback 会用保留 transcript 的 `project_id` 补回裸 ID 节点。修复后空集合始终输出 `[]`，且存在权威缓存时项目集合只由 active cached projects 决定。
