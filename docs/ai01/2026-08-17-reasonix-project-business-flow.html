先给出三个关键结论

这里的“同步”是项目域共享，不是两个用户账号或两台设备的全量镜像。

INVITATION & SYNC 能共享项目数据，但不是实时全账号同步

邀请被接受后，被邀请者成为项目 active member，可读取并协作同一个云端项目。项目、事项、动态、标签、资产等以云端为准；当前实现主要通过请求与手动刷新拉取，代码审计未发现项目级 WebSocket / SSE 推送。

ASSET STORAGE 文件在私有 OSS，关系数据在 PostgreSQL

二进制对象写入阿里云 OSS 私有桶；文件元数据、版本、目录、引用、处理状态和清理任务写入 PostgreSQL。下载使用约 10 分钟有效的签名 URL。

LOCAL BOUNDARY 本地内容不随邀请共享

本地工作区、会话记录、分支元数据、已安装技能/连接器、本地计划任务与缓存仍属于当前设备和账号范围。

01 · 端到端主流程

九个业务关口贯穿所有参与方。云端负责身份、成员关系和权威状态；桌面端负责交互、本地会话与本地执行。

关键成员激活 云端与管理端边界 普通业务动作 所有连线均表示顺序关系，不表示实时推送。

02 · 邀请与项目数据共享

邀请 token 只在创建时返回明文；数据库保存 HMAC。接受成功后建立 active membership，并把加入事件写入项目动态。

03 · 生命周期与邀请状态

归档是可恢复的只读状态；删除是云端硬删除并进入对象清理流程，但不删除用户的本地目录。

04 · 资产上传、读取与删除

二进制和业务元数据分离存储。SHA-256 在流式上传中计算；私有对象永不直接公开。

05 · 数据归属与存储架构

CloudProject 不等于 LocalWorkspace。缓存和命令日志只用于离线体验、恢复与幂等，不是项目权威数据库。

项目域权威关系数据 云边界 本地或只读组件

06 · 功能全景台账

桌面端当前项目界面包含动态、计划、任务、资产四个页签，以及右侧项目配置区。

PROJECT SHELL

项目入口与生命周期

  • 创建项目、领取新手引导项目、列表、详情、重命名与描述编辑
  • active / archived 切换；归档时只读；所有者可删除
  • 项目树刷新、离线缓存回退、当前项目与本地工作区可选绑定
ACTIVITY

动态与协作

  • 项目动态流、消息发布、已读游标、按 client message id 恢复
  • 消息提及成员；从项目资产或本地上传中选择附件，单次最多 10 个
  • 成员列表、创建/查看/撤销邀请、接受邀请、移除成员
WORK ITEMS

计划与工作项

  • 创建、详情、编辑、移动状态、删除
  • 看板、表格、列表、甘特、日历
  • 搜索、负责人、优先级、标签筛选
  • 状态：待办 / 进行中 / 暂停 / 完成
LABELS

标签与视图

  • 标签新增、改名、改色、删除
  • 工作项绑定 / 解绑标签
  • 自定义保存视图当前仅在本次项目页面会话有效
ASSETS

资产与目录

  • 上传、列表、目录树、改名、移动、下载、删除
  • 目录新增、编辑、删除
  • 绑定工作项或动态消息
  • 查看扫描、解析、索引与清理状态
INSTRUCTIONS

项目指令

  • 项目级 human / agent 指令
  • 版本号与内容 hash
  • 新会话固定不可变快照；发送前验证项目 scope 和状态
CAPABILITIES

连接器、专家、技能

  • 云端保存绑定定义与参数
  • 实际执行仍受本地安装、权限和审批影响
  • 能力配置属于 owner-only
AUTOMATION

自动化

  • 云端定义：名称、提示词、模型、能力引用、启用状态
  • once / daily 计划保存为本地任务
  • 运行认领、租约、回收、放弃、结果和重复风险确认
PROJECT TASK

本地运行历史

  • 项目范围筛选、搜索、详情
  • 重命名、移入废纸篓、恢复
  • 与云 WorkItem 是两种不同对象
SESSION

项目会话与执行边界

  • 从项目创建会话并固定指令/能力快照
  • 本地目标绑定工作区；当前工作树也包含无 workspacePath 的 cloud target 入口
  • 归档、离线或 scope 不一致时阻止可写执行并降级只读
ADMIN

管理端只读治理

  • 项目列表、详情、状态、所有者、版本、工作项聚合
  • 成员数、消息/系统事件、资产容量与处理管线、自动化运行聚合
  • 故意不暴露项目内容、用户身份明细、文件元数据与 OSS object key；无冻结/封禁/导出动作

07 · 权限与同步矩阵

“成员可协作”不等于“成员可配置治理”。所有者负责生命周期和高风险设置。

业务域所有者普通成员权威位置同步 / 刷新语义
项目基本信息 / 归档 / 恢复可写只读PostgreSQL写入后回读；其他客户端再次请求可见
成员 / 邀请 / 删除项目可管理不可管理PostgreSQL接受邀请建立 active membership
工作项 / 标签可协作可协作PostgreSQL共享项目状态；通过请求刷新
动态 / 消息 / 已读可协作可协作PostgreSQL消息与附件关系共享；界面有手动刷新
项目资产 / 目录可协作可协作OSS + PostgreSQLactive member 可列出 / 下载当前项目资产
指令 / 能力 / 自动化定义可配置只读或不可配置PostgreSQL定义共享；实际可用性仍取决于本地
本地工作区 / 会话 / 分支当前设备各自设备本地文件系统不随项目邀请同步
本地计划任务 / 运行历史当前设备各自设备本地自动化服务与云端定义关联，但不是云 WorkItem
管理端治理无管理入口无管理入口只读 Admin API仅聚合，不回写项目
同步结论

邀请者和被邀请者会基于同一个 CloudProject 权威数据协作；当前实现不承诺毫秒级实时推送，也不会同步用户完整账号数据或设备本地内容。若产品目标是“实时协同”，还需要明确事件推送、冲突合并、在线状态与离线重放协议。
