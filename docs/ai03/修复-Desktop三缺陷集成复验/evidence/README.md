# Desktop 集成复验证据索引

本目录按用户要求只保留文档化证据。真实 Desktop 测试期间生成并核验过逐次 JSON、CSV、截图、日志、
fixture、统计脚本和浏览器输出；这些原始工件不进入产品修复 PR。报告中的聚合数字、判定、时间线、
缺陷现象、复现步骤、产品身份和验证结果已经转录到 Markdown 文档。

历史文档中以代码格式出现的原始文件名用于标识当时的取证来源，不表示对应文件仍在仓库中，也不是
可点击链接。修复前完整外部归档的位置、文件数、大小和 SHA-256 记录在 `before/README.md`；该归档
不属于本 PR 的版本化内容。

- `before/`：三缺陷修复前的基线、方法、阶段报告、最终报告和缺陷记录。
- `after/`：三缺陷集成后的校准、low 24、auto 6、严格 12、最终报告和剩余问题记录。
- `post-sync/`：同步最新 `main-v3` 后的三场景真实 Desktop 冒烟报告。

Draft PR 整理时从 `origin/main-v3@d68363ff` 重建产品集成提交 `17b7ee41`。经 Git blob 对比，重建提交
在 `desktop/` 与 `internal/` 的 26 个产品/测试文件上和真实冒烟所用 `db39ae76` 完全一致，因此整理只
改变集成拓扑与证据保留方式，不改变已经验收的产品实现。

本目录不包含 Provider 凭据、运行时 profile 或生成 workspace。
