## 必须保留的行为

1. 继续直接调用 `$SYSDIR\taskkill.exe`。
2. 参数保持 `/IM "${PRODUCT_EXECUTABLE}" /T /F`。
3. 命令执行完成后才继续卸载。
4. 保留现有 `Sleep 1000`。
5. `taskkill` 非零退出码不单独中止；仍尝试删除主程序。
6. 删除失败且主程序仍存在时继续 `Abort`，文案不变。

## 实现要求

- 用 NSIS 随附的 `nsExec::Exec` 取代该处 `ExecWait`。
- 调用后 `Pop $0` 消费返回值，避免污染 NSIS 栈。
- 合同测试必须同时断言隐藏执行路径存在、参数不变、返回值已弹出，并拒绝
  `ExecWait` 再次直接调用同一 `taskkill.exe`。
- 保持相关文件 LF，不做无关格式化。

## 验收标准

- AC-01：应用运行时交互式卸载，全程没有终端或命令行窗口闪现。
- AC-02：应用及其进程树仍被结束，主程序随后成功删除。
- AC-03：应用未运行时卸载成功且无终端闪现。
- AC-04：`/S` 路径不创建额外可见窗口。
- AC-05：删除最终失败时仍中止卸载，不能报告假成功。
- AC-06：安装器合同测试能阻止恢复为 `ExecWait taskkill.exe`。
- AC-07：实际 NSIS installer 构建成功。
