## 任务目标

当模型广场首次 cache-only 读取明确没有可用价格缓存时，在一次应用生命周期内自动调用
现有远端刷新一次；成功后展示目录，失败后保留手动恢复，不产生自动重试或重复请求。

## 实现约束

- 自动尝试资格由 `App` 实例持有，不能使用模块级全局变量。
- 资格领取必须同步且幂等，能抵御 Strict Mode effect 重放。
- 自动刷新判定只接受：来源为空，或全部来源均为 `unavailable` 且无模型。
- 自动和手动刷新使用同步 in-flight 引用防重，不能仅依赖异步 React state。
- 只有实际刷新调用继续触发一次 `onMarketplaceChanged`。
- 避免无意义抽象；辅助函数应可直接测试或由行为测试覆盖。

## 验收标准

1. fresh 且有模型：一次 cache-only load，零次 refresh。
2. stale 但有模型：一次 cache-only load，零次 refresh，仍展示缓存。
3. fresh 空目录：零次自动 refresh。
4. 无来源：自动 refresh 一次。
5. 全部来源 unavailable 且无模型：自动 refresh 一次。
6. 自动刷新成功：展示新目录并调用一次 `onMarketplaceChanged`。
7. 自动刷新失败或返回 unavailable：不自动重试，显示现有恢复提示。
8. 自动失败后手动点击：允许再次 refresh。
9. 使用同一 App 级领取器重新挂载：第二次进入不自动 refresh。
10. 自动 effect 与手动点击重叠：同一时刻最多一个 refresh in flight。
11. 既有模型选择、外链、筛选、价格展示及 44 项组件契约无回归。
