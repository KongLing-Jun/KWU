## 实施约束

- 关闭宽限使用约 150ms 的单一局部计时器；打开任一菜单前先取消待关闭计时器。
- 离开事件仅在 `hoverMenus=true` 时安排关闭；非悬浮模式不注册新的关闭效果。
- 组件卸载必须清理计时器；不得留下卸载后回调。
- 关闭回调应清空确认态和受控菜单，且不能让旧计时器关闭已切换的新菜单。
- 使用现有 React/TypeScript 能力，不新增依赖或抽象通用 hook。
- 保持 LF；提交前检查 `git ls-files --eol`、实际 diff、状态和禁止文件范围。

## 验收标准

1. 悬浮“总结”打开对应面板，按钮 `aria-expanded=true`。
2. 从按钮穿过间隙进入面板，在 150ms 宽限后仍保持打开。
3. 离开按钮与面板并推进计时器后关闭，`aria-expanded=false`。
4. 宽限期内重新进入取消关闭。
5. 悬浮另一个按钮会切换菜单，旧计时器不会关闭新菜单。
6. 悬浮模式点击已打开按钮不关闭或固定面板；随后离开仍关闭。
7. 非悬浮模式点击开关行为保持不变。
8. 组件卸载清理计时器，无 React 警告或悬空更新。
9. 无允许范围外生产代码、样式、契约或依赖变更。
