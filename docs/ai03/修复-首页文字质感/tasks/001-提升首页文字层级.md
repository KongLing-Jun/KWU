# 001 提升首页文字层级

## 目标与产物

在不改变布局和交互的前提下，按 WorkBuddy 源码对齐 Reasonix 首页侧栏文字层级，并保留主题色图标。

产物：限定于 `.app--creation` 的 CSS 调整、对应样式契约测试和本任务完成回执。

## 依赖与依据

- 依赖已确认的 `../plan.md`。
- 首页视觉隔离边界位于 `desktop/frontend/src/styles/theme-overrides.css`。
- 主题文字 token 位于 `desktop/frontend/src/styles/tokens.css`。
- 现有契约位于 `desktop/frontend/src/__tests__/workbuddy-creation-theme.test.ts`。

## 允许范围

- 修改 `desktop/frontend/src/styles/theme-overrides.css` 中首页文字相关规则。
- 修改 `desktop/frontend/src/styles/features.css` 中首页导航当前项字重。
- 修改 `desktop/frontend/src/App.tsx`，仅以既有空白会话状态补充“新建对话”的当前项类名和 `aria-pressed`。
- 修改首页视觉契约测试。
- 更新本任务和 `progress.md`。

## 禁止范围

- 不修改 React 结构、业务逻辑、后端和数据契约。
- 不修改全局字体族或引入字体资源。
- 不调整页面布局、控件尺寸或主题持久化。

## 保持行为

- 导航、模式和场景按钮交互不变。
- 任务时间、辅助标签和状态继续保持次级层级。
- 深浅主题与所有视觉方向继续使用同一套主题 token。
- 窄窗口响应式布局不变。

## 验收标准

- 主导航普通态使用 `13px / 400` 主文字色，当前项使用 `600`；空白首页的“新建对话”为当前项；图标保持主题色。
- 普通任务标题使用 `13px / 400`，选中任务使用 `600`，时间继续保持浅色。
- 导航使用 WorkBuddy 的 `Arial` 栈，任务标题使用其系统字体栈；两者为 `22px` 行高和 `antialiased`。
- 会话行悬浮、键盘焦点或菜单打开时直接复用“任务”标题的 `--sidebar-hover` 中性灰背景、透明边框和 `600` 字重；当前会话持续使用该背景和字重并保留左侧竖线。
- 置顶与归档按钮默认透明且无可见边框，仅直接悬浮/聚焦时显示 `--sidebar-hover`；置顶主题色和归档警示色保留。
- 本次不改变模式、场景和输入提示。
- 契约测试和前端构建通过。
- 内置浏览器真实页面无视觉布局回归。
