# 任务 001：实现重置密码错误提示

## 状态与分配

- 状态：实施中。
- 执行与审查：主会话；用户授权本小改动合并文档、任务和代码交付。
- 对应 PR：一个独立 Draft PR。

## 目标与产物

- 重置密码页显示上下文正确的确定中文错误。
- 重置页三个确认字段复用登录/注册的必填标识和字段下方空值错误。
- 密码不一致继续在前端拦截，不调用云端。
- 登录、注册、全局错误映射和安全 fallback 不变。
- 直接测试、方案、进度和本完成回执随代码交付。

## 依赖与证据

- 方案：`../plan.md`。
- Codegraph 与云平台源码证据见方案“调查基线与证据”。
- `AccountCenter.tsx` 的错误提交和最终横幅是两个 presentation 点。
- 云端密码重置没有 `PASSWORD_MISMATCH`；`INVALID_CREDENTIALS` 合并未知手机号和非普通用户。

## 允许范围

- `desktop/frontend/src/features/account/ui/AccountCenter.tsx`
- `desktop/frontend/src/locales/zh.ts`
- `desktop/frontend/src/__tests__/account-center-registration.test.tsx`
- `docs/ai03/修复-重置密码错误提示/`

## 禁止范围

- 不修改 Go、云端 API、bridge、Store、全局 `clientError` 或持久化结构。
- 不修改登录/注册交互，不新增通用 UI 组件、依赖或遥测。
- 不展示云端原始消息，不记录手机号、密码、验证码或 CAPTCHA proof。
- 不改变成功重置、短信 cooldown、CAPTCHA 和敏感值清理行为。

## 验收标准

- 本地密码不一致：明确中文、无通用 fallback、bridge 调用为零。
- 三个确认字段显示红色 `*` 和 `required` 语义；空值点击后各自在字段下方报错，
  聚焦短信验证码且 bridge 调用为零。
- 云端 `PASSWORD_INVALID`：显示新密码长度提示。
- 云端 `INVALID_CREDENTIALS`：显示不枚举账号状态的重置提示。
- 云端验证码过期：显示既有确定中文。
- 原始云消息不进入横幅，技术 code/request ID 保持。
- 登录/注册已知码和未知码 fallback 不回归。
- 既有成功重置请求与成功提示保持。

## 聚焦验证

```powershell
pnpm exec tsx src/__tests__/account-center-registration.test.tsx
```
