# 任务 001：降低消息通道卡片重绘开销

## 执行合同

| 项目 | 内容 |
| --- | --- |
| 状态 | 已完成 |
| 目标 | 消除低性能 Windows/WebView2 环境中的消息通道卡片悬浮色块 |
| 允许范围 | `desktop/frontend/src/styles/settings.css` 及本任务回执 |
| 禁止范围 | 其他页面卡片、业务逻辑、后端、依赖和 WebView2 全局启动参数 |

## 实现结果

- `.bot-catalog-card` 不再执行过渡、位移或阴影动画。
- 悬浮仅更新卡片边框，不再切换整块背景。
- `.bot-catalog-card__action` 使用透明背景，不再单独响应父卡片悬浮变色。
- `focus-visible` 使用父卡片轮廓提供键盘焦点反馈。

## 偏差、风险与回滚

初版只移除卡片位移、阴影和过渡，仍可在操作图标附近复现色块；根据截图和源码证据，
进一步取消父卡片背景切换及子元素独立悬浮重绘。范围仍局限于消息通道卡片。

若出现不可接受的视觉回归，可整体回滚本任务 CSS 修改；无数据迁移或兼容性清理。
