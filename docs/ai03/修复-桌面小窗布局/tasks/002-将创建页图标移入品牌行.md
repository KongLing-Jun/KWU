# 002 将创建页图标移入品牌行

## 执行契约

- 目标：在所有窗口尺寸下将创建页图标与“云智企办”放在同一品牌行，移除绝对定位 mascot 造成的贴顶风险。
- 产物：简化的创建页品牌 DOM、限定在创建页的同行样式和结构/CSS 契约测试。
- 依赖：[plan.md](../plan.md) 已稳定并提交；与任务 001 无技术依赖，但按单实现代理约束在其后串行执行。
- 执行顺序：串行组 B。
- 建议实现提交：`fix:调整创建页品牌图标布局`。
- 建议回执提交：`docs:记录创建页品牌布局修复结果`。

## 证据与实现基础

- `BrandLockup` 已渲染 `.welcome__brand-logo` 和 `.welcome__brand-name`，普通欢迎页正在使用该结构。
- 创建页又渲染 `.welcome-creation__mascot`，导致同一 logo 出现两个 DOM 节点。
- 创建页 CSS 把 `.welcome__brand-logo` 设为 `display: none`，再把 mascot 绝对定位到品牌行上方 `10px`。
- 现有矮窗口规则已定义品牌图标/文字尺寸变量，可继续使用；mascot 的容器和矮窗口隐藏规则可删除。

## 允许范围

- `desktop/frontend/src/components/Welcome.tsx`
- `desktop/frontend/src/styles/theme-overrides.css`
- `desktop/frontend/src/__tests__/welcome-creation-modes.test.tsx`

## 禁止范围

- 不改变 `BrandLockup` 的非创建欢迎页表现。
- 不改变创建模式列表、场景列表、文案、交互、选中状态或可用性契约。
- 不调整输入框、侧边栏、聊天容器或全局品牌资产。
- 不新增图片资产、组件抽象或实现一次性 JavaScript 尺寸检测。

## 必须保持的行为

- 品牌文字、标题、三个创建模式和场景按钮保持。
- 矮高度下的品牌尺寸变量、场景隐藏与模式隐藏规则保持。
- logo 仍是装饰性图像，保留空 `alt`、`aria-hidden` 和禁止拖拽。
- 品牌行只在 `.app--creation .welcome--creation` 中获得新样式。

## 验收标准

1. 创建页只有一个 `.welcome__brand-logo`，且它是 `.welcome__brand` 内“云智企办”之前的同行元素。
2. `.welcome-creation__mascot` 不再出现于 DOM 或 CSS。
3. 创建页不再隐藏 `.welcome__brand-logo`，品牌行具有清晰的水平间距并垂直居中。
4. `1200 × 800`、`1240 × 800` 和大尺寸下，品牌行不贴顶，不与标题、模式、场景或输入框重叠，Composer 完整可见。
5. 创建模式与场景交互的现有聚焦测试全部通过，生产构建通过。
6. 改动仅落在允许文件内，EOL 保持 LF。
