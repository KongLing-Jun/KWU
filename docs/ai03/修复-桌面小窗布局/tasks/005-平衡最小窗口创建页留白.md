# 005 平衡最小窗口创建页留白

## 执行契约

- 目标：保持最小窗口高度 `800px`，将创建页空状态内容整体下移约 `24px`，改善上下留白不对称。
- 产物：创建页限定高度规则与对应样式契约测试。
- 依赖：任务 001 至 004 已完成，窗口下限和创建页组件尺寸已稳定。
- 交付切片：一个 `fix:` 实现提交，验证通过后一个 `docs:` 回执提交。

## 证据与边界

- 用户最小窗口截图中，品牌上方留白约 `100px`，Composer 下方留白约 `150px`，内容视觉中心偏上约 `25px`。
- 原生最小窗口在系统缩放下可能落入 `700px` 以下的 CSS 可视高度；只修改 `min-height: 701px` 规则无法覆盖该运行态。
- Codegraph 确认目标链路限定于创建页空会话的 `main → Welcome → Footer/Composer`，普通消息页不消费该状态选择器；worktree 当前源码与测试已直接核对。
- 不改变 `1200 × 800` 原生窗口下限、Composer 尺寸、场景交互、普通会话或极矮紧凑布局。

## 实现与验收

- CSS 可视高度 `431–700px` 时增加固定 `24px` 顶部偏移，覆盖系统缩放后的原生最小窗口。
- CSS 可视高度 `701–900px` 时在既有位置上增加最多 `24px` 偏移，并随高度平滑归零；`900px` 及以上保持原位置。
- Playwright 计算样式验证：`640px → 24px`、`793px → 174px`、`900px → 150px`。
- `pnpm exec tsx src/__tests__/welcome-creation-modes.test.tsx` 通过，82 项断言全部成功。
- `pnpm build`、`git diff --check` 通过；两个实现文件保持 LF。

## 分配与状态

- 分配：主会话按轻量流程实现并验证。
- 状态：实现、聚焦测试、生产构建和浏览器高度契约验证已完成；标准 dev profile 原生应用保持打开，等待用户最终视觉确认。
- 偏差：原生窗口检测到用户正在操作后停止自动化，未抢占用户窗口继续截图。
- 剩余风险：不同系统缩放比例下的最终视觉重心仍以用户原生窗口观感为准。
