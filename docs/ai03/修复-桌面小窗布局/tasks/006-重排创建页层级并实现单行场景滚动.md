# 006 重排创建页层级并实现单行场景滚动

## 执行契约

- 目标：保留创建页四行内容，将前三行居中，把第四行二级场景改为 WorkBuddy 同类的单行横向滚动条，并让最小到最大化之间的整体纵向位置连续收敛到居中。
- 产物：创建页滚动状态与箭头交互、限定样式及聚焦测试。
- 依赖：任务 001 至 005 已完成；本任务先于任务 007 实施，便于独立审查视觉与交互。
- 交付切片：一个 `fix:` 实现提交，验证通过后一个 `docs:` 回执提交。
- 建议实现提交：`fix:实现创建页单行场景滚动`。
- 建议回执提交：`docs:记录创建页场景滚动结果`。

## 证据与实现基础

- `Welcome.tsx` 已按品牌、动态 Slogan、一级模式、二级场景的顺序渲染四层内容，不需要删除任何层级。
- 当前 `.welcome-creation__scenario-list` 使用 `flex-wrap: wrap`；“更多”展开会渲染第二个列表，无法保持单行。
- 当前 CSS 已存在渐隐和箭头选择器，但没有对应的滚动状态类、箭头 DOM 或处理函数。
- WorkBuddy 源码的 `QuickActions` 以 `overflow-x` 单行列表承载场景，根据左右可滚动状态渲染箭头与渐隐，箭头调用步进滚动。
- Codegraph 显示 `Welcome` 是目标 DOM 的生产者，`CreationScenarioSkill` 继续由 `Transcript` / `App` 消费；不需要改变 Prompt/Skill 数据流。

- 不改变场景到 Prompt/Skill 的数据流、选中语义或 Composer。
- 不修改 WorkBuddy 安装目录或复制其品牌资产。
- 不实现截图红框，不新增依赖或通用轮播组件。
- 不修改侧边栏；侧边栏由任务 007 独立处理。

## 必须保持的行为

- 四行顺序固定为：图标 + 品牌名、动态 Slogan、一级模式、二级场景。
- 一级模式切换、禁用态、`aria-pressed`、场景选择和 Skill 插入契约保持；删除“更多”控制及其展开状态。
- 二级场景按钮继续使用现有主题自适应全圆弧胶囊样式。
- 极矮窗口现有场景隐藏与模式隐藏规则保持。

## 验收标准

1. 品牌行、动态 Slogan、一级模式均水平居中，四行内容完整保留。
2. 二级场景条居中，标准宽度上限为 `656px`，约为 `760px` Composer 的 `86%`；窄容器按 `calc(100% - 32px)` 自适应缩小。
3. 三个一级场景分别直接显示各自完整的二级标题集合，不区分 featured / additional，也不显示“更多”。
4. 总宽 `656px` 内始终保留左右箭头固定槽；无溢出时不显示箭头或渐隐，溢出时箭头显示在标题区之外，渐隐只覆盖中间滚动区，标题不被遮挡且整行不横向跳动。
5. 箭头点击触发平滑横移；到达边界后对应箭头消失。
6. 切换一级模式后滚动回起点并重新计算状态；窗口尺寸变化后状态收敛。
7. 键盘焦点和无障碍属性保持，聚焦测试与生产构建通过。
8. 最小窗口保持紧凑位置；随高度增加，品牌至 Composer 整体连续移动，最大化时在 Topicbar 以下的主区纵向居中，不在相邻高度断点发生跳变。

- 剩余风险：当前 Windows 系统缩放与原生 WebView 已通过；其他 DPI 缩放比例仍可能使箭头首次出现位置产生细微像素差异，但不改变单行和方向状态逻辑。
- 交接说明：创建页保持品牌、动态 Slogan、一级模式、二级场景四行；前三行居中，第四行宽度上限为 `656px`，在标准 Composer 下约占 `86%`，窄容器保留左右安全间距。三个模式各自的全部二级标题共用一个可拖拽、滚轮可横移的单行列表；不保留“更多”。左右各固定预留 `20px` 箭头槽，中间视口独立承载标题和渐隐，列表上下各留 `2px` 安全空间，按钮显隐和纵向裁切均不会挤压或覆盖胶囊；滚动状态只保存左右布尔值，模式切换会复位到起点。
