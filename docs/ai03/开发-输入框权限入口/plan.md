# 输入框权限入口改造计划

## 背景与现状

聊天输入框的工具权限入口在宽容器中是三段式切换条，在紧凑容器中才是纯图标按钮。前者会随权限状态改变控制内容，后者又缺少文字语义，容易造成工具栏视觉跳动。两种入口共享现有的三项权限浮层：需要批准（`ask`）、自动批准（`auto`）、完全访问（`yolo`）。浮层当前用勾选图标标出活动项。

源代码证据（基线 `origin/main-v3` 的 `c364c31f`）：

- `desktop/frontend/src/features/composer/ui/Composer.tsx` 同时渲染三段式 `.composer-modebar--approval` 与紧凑 `.composer-approval-trigger`；后者已通过 `AnchoredPopover` 复用三项菜单和 `onSetToolApprovalMode`。
- `desktop/frontend/src/styles/session.css` 把三段式入口设为 `232px`，在容器小于 `760px` 时隐藏它并显示 `32px` 的纯图标入口。
- `desktop/frontend/src/__tests__/composer-responsive-toolbar.test.tsx` 已覆盖三个菜单项、当前项无障碍状态、键盘导航和选择回调复用。
- `desktop/frontend/src/styles/theme-overrides.css` 另有创建页 28px 极窄覆盖，必须同步调整以保证任何宽度均保留文字。

## 已确认的产品决策

- 所有窗口宽度均展示固定宽度的「权限图标＋当前权限文案」入口，不降级为仅图标；ask、auto、yolo 分别展示「需要批准」「自动批准」「完全访问」。
- 入口使用稳定固定宽度，避免权限状态或响应式切换导致工具栏抖动。
- 保持当前悬浮置灰、点击展开、点击权限后切换并回到输入框的交互。
- 继续使用已有三种权限及其现有描述、状态回调与键盘导航。
- 弹出菜单不再显示当前选项的视觉勾选；不改变 `aria-checked` 的状态语义。
- 弹出菜单固定为紧凑的 176px 宽度，仅显示图标和名称；完整说明保留在悬停提示和无障碍名称中。

## 目标与非目标

目标：统一桌面和紧凑布局的入口外观，降低输入工具栏布局变化，并去掉菜单中冗余的勾选图标。

非目标：不修改权限策略、默认权限、后端/桥接接口、权限文案含义、菜单定位逻辑或其它输入框控件。

## 实现方案

1. 在 `Composer.tsx` 移除三段式按钮组，保留并提升现有权限触发器为全部断点使用的单一入口；触发器显示当前权限图标和对应的权限文案。
2. 保持已有 `AnchoredPopover`、`chooseCompactApprovalMode`、菜单角色及焦点导航；菜单项点击仍调用原有权限设置回调。
3. 移除菜单项末尾的 `Check` 图标及其不再需要的导入；保留活动项的无障碍属性和必要的样式状态。
4. 在 `session.css` 把权限控制区及触发器尺寸固定为可容纳图标和四字文案的宽度，删除其小窗口图标化覆盖；同步调整 `theme-overrides.css` 的创建页极窄覆盖，防止主题层将入口重新压回图标尺寸；维持悬浮、焦点、打开和禁用态。
5. 更新聚焦的 composer 响应式工具栏测试，验证所有容器宽度的入口内容和固定尺寸、三项菜单、无勾选渲染、选择回调及键盘可达性；运行前端生产构建。

## 兼容性、风险与回滚

权限值及桥接契约完全不变，风险限于窄窗口工具栏可用空间。固定入口比现有紧凑图标多占空间，需在现有最小容器测试场景确认其他控件仍可用且不溢出。若出现布局回归，回滚本变更即可恢复原来的分段/图标入口，不涉及数据迁移。

## 验收标准

- 任意窗口宽度下，权限入口均显示权限图标与当前权限文案，宽度稳定；ask、auto、yolo 分别为「需要批准」「自动批准」「完全访问」。
- 悬浮、键盘焦点、打开和禁用视觉状态保持可辨识。
- 点击入口打开现有三种权限菜单；点击任意项继续调用原权限切换回调并关闭菜单、把焦点交回输入框。
- 菜单不渲染勾选图标，但当前项仍以 `aria-checked` 供辅助技术识别；三项仅显示图标和名称，菜单宽度为 176px。
- 最窄现有 composer 响应式场景不发生工具栏溢出或不可操作控件。

## 验证计划

- 运行修改后的精确 composer 响应式工具栏测试。
- 运行 `pnpm build`（在 `desktop/frontend`）。
- 用桌面前端的可访问环境检查常规与最窄窗口下的入口、浮层和权限切换路径。
