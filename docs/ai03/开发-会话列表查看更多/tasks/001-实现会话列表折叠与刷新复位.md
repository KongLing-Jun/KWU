# 001 实现会话列表折叠与刷新复位

## 目标与产物

在 Reasonix 侧栏实现任务/工作空间会话“查看更多 / 收起”交互，并确保刷新时能自动揭示位于第 6 条以后的持久化当前会话；交付代码、文案、样式、测试与本任务完成回执。

## 依赖与证据

- 依赖已批准的 `../plan.md`。
- `ProjectTree.tsx` 同时拥有树数据、分区渲染、当前会话定位和可见快捷键收集，是最小扩展点。
- WorkBuddy 安装包前端定义的阈值为 5；全局任务和每个空间内部会话各自管理显示全部状态。

## 允许范围

- `desktop/frontend/src/features/workspace/ui/ProjectTree.tsx`
- `desktop/frontend/src/locales/zh.ts`
- 与本交互直接相关的侧栏 CSS
- 新增或调整 `ProjectTree` 聚焦测试
- 本目录中的计划、进度和任务回执

## 禁止范围

- 后端 Go、会话存储、项目树协议、删除/归档语义
- 置顶区分页或工作空间总列表截断
- 无关的侧栏视觉重做
- PR、发布或合并操作

## 保持行为与约束

- 继续使用当前排序结果作为“前 5 条”的顺序。
- 搜索、时间筛选、整体分区收起、文件夹收起、重命名、菜单、拖拽和创建任务保持可用。
- 隐藏节点不得出现在数字快捷键目标中。
- 展开状态仅在当前页面生命周期内有效，不写入持久化存储。
- 刷新或组件重新挂载后，当前会话在前 5 条时保持折叠；在第 6 条以后时自动展开所属分组。
- 自动展开后切换到近期会话不得自动收起；用户主动收起后，同一页面生命周期内不得再次自动撑开该分组。

## 验收标准

采用 `../plan.md` 的九个验收场景；聚焦测试和生产构建必须通过，且内置浏览器实际交互无控制台错误。
