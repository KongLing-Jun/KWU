## 真实应用验收

使用本分支`wails dev`完成一条全新的真实流程：

1. 新建会话并选择真实专家团，由主专家回复且至少调度一个配置成员；确认成员页签与只读历史可打开。
2. 完成后切换到另一个会话再返回；确认团队、成员、父 transcript和已落盘 child历史未丢失。
3. 完全重启开发应用；确认会话仍为`team_active`，团队和成员页签恢复，child历史只读可打开。
4. 退出专家团；确认当前父 Agent恢复普通身份、历史工作区仍在、原会话选择专家被拒绝并提示新建。
5. 再次完全重启；确认`team_archived`、团队标识、成员页签和 child历史仍在。
6. 在 archived会话继续普通聊天并触发一个普通 task；确认新 task不进入旧成员页签且旧历史不变。
7. 只读检查新父 Session的 sidecar和 owned child meta，确认状态/所有权与 UI一致；不编辑文件。

应用验收必须记录所用开发命令、会话标识、关键观察结果和任何工具限制。若内置浏览器无法覆盖 native
Wails交互，按仓库规则使用 Computer Use；只有自动化工具无法可靠执行或需要用户凭据时才请用户代测。
