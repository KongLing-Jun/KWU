## 目标

把专家团建模为父 Session 上的持久状态与固定成员到 `subagentRef`绑定，复用任务 001 的 task
Runtime，使切换会话、重启、退出团队和父历史分支后行为确定。

## 预期产物

- 父 sidecar持久化 `normal / team_active / team_archived`、团队快照与成员当前 ref。
- 主专家仍使用父 Session；首次成员 task fresh，后续自动 continue。
- 专家工具集只提供持久 task/wait_task/stop_task，不提供 read_only_task/parallel_tasks。
- 同成员串行，不同成员可分别启动后统一等待。
- 团队退出保留成员/ref历史只读，同会话禁止再次召唤。
- fork/rewind 后新时间线清除活动绑定，下一次成员 task fresh。

- `Member`已有 ExpertID、Name、Role、AvatarKey和配置顺序，可生成父Session内稳定 memberKey。

## 实现约束

1. identity prompt只能追加到现有基础 system prompt；归档团队移除主专家追加指令。
2. 模型永远不选择任意 ref；宿主按 member_name解析可信 memberKey/ref。
3. member display name规范化后必须唯一；持久键优先复用 ExpertID。
4. 绑定只在 child启动成功后写入；保存失败不得留下虚假 ref。
5. team_archived保留非敏感显示快照和ref，不保存私有prompt/A2A信封。
6. 普通会话升级前的child不得绑定成员。
7. fork/rewind不复制或截断child transcript，只清空新时间线活动绑定。
