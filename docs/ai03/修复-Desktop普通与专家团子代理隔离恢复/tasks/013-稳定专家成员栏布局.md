# 任务 013：稳定专家成员栏布局

- 状态：已完成。
- 串行组：Serial-13。

## 目标与交付物

把专家成员栏稳定固定在 Transcript 底部，以一层不透明主题底板承载平面成员按钮，消除 transcript
透叠、多层背景和常态阴影，同时保留现有 TodoPanel/Composer 顺序、主/子专家切换、横向滚动、
无障碍反馈及任务状态点。

交付物：

- 共用专家成员栏 CSS 的最小调整；
- persisted `ExpertTeamSession` 与 legacy `AgentWorkspace` 的布局回归；
- Frontend 构建和真实 Desktop 视觉验收回执。

## 禁止范围

- 不修改 Composer DOM、尺寸或模型选择器。
- 不调整 TodoPanel、提示条和 Composer 在外部 footer 中的现有顺序；这些区域可以位于成员栏下方。
- 不修改 task Runtime、事件、Session、sidecar、成员绑定和历史 bridge。
- 不改变成员出现条件、顺序、头像、状态颜色或子历史只读合同。
- 不处理普通聊天内容、任务卡、待办面板和父 Agent 文案。

## 验收标准

1. 专家团主/子历史中的成员栏始终固定在 Transcript 底部，滚动时保持可见；TodoPanel等现有
   footer区域可以位于其下方。
2. 成员栏是覆盖整行的不透明主题底板，后方 transcript/tool/todo 不透出。
3. 选中和未选中成员按钮使用相同的低对比度主题中性底色且无阴影；选中态仅增加主题前景色细边框，
   hover/focus时中性底色加深。
4. 主/子视图切换不改变成员栏位置，不造成 Composer 或 transcript 大幅形变。
5. 窄窗口仍保持单行横向滚动，所有成员可访问。
6. 黄/绿/红状态点、未调用隐藏、主专家返回和普通聊天无成员栏均保持。
