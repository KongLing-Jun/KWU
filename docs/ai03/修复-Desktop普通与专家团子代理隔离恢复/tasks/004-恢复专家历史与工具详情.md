修复归档child工具详情路由，并验证父会话回收站对新task生命周期的整体移动/恢复/删除。

## 预期产物

- 团队归档后成员历史仍可查看，无composer且可返回主会话。
- 移入回收站先停止running child并一起移动；恢复/永久删除保持父子一致。

## 实现约束

1. child页面只是父任务壳内的只读内容切换，侧栏仍选中父Session。
2. 任务004交付时，system prompt、A2A信封、job ID等内部控制字段不得进入用户历史。
3. child tool查询必须先验证ref属于当前父；not-found不得回退父查询。
4. archived团队只读；任何新普通child不得进入旧成员历史。
5. 回收站移动必须等待/收口running task后再移动JSONL，避免后台重新写回。
6. restore不自动重启interrupted turn；永久删除不遗留child meta/session。

> 后续合同：第2条是任务004交付时的隐私边界。任务015允许task详情显示复用job ID形成的不透明
> `task_run_id`与依赖引用；其他job控制字段、system prompt和A2A信封仍不得进入用户历史。
