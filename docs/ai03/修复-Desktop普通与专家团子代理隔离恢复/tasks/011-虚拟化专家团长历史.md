## 目标

复用现有 Transcript 虚拟化能力，为专家团主专家和子专家历史建立相同的同时挂载 DOM 上限，关闭
“长子历史 → 主历史 → 其他会话 → 返回”触发 WebView `STATUS_BREAKPOINT`的覆盖缺口。

## 实现合同

1. 抽取或复用现有 `@tanstack/react-virtual`行虚拟化，不新建第二套滚动容器或独立历史协议。
2. 普通 Transcript 现有阈值、动态测量、overscan、问题定位和滚动恢复行为保持不变。
3. 专家团 overview 和 focused child 历史达到阈值后，只挂载视口附近的行；短历史仍直接渲染。
4. 专家团继续使用 Transcript 的唯一滚动容器；成员栏、返回按钮和只读 composer 外壳保持现状。
5. child 分页、工具详情、成员绑定、task 状态、事件投影和持久化合同不得改变。
6. 本任务不处理成员状态点颜色或实时终态刷新。
