## 目标

1. 显式停止父 turn时保留整轮父 Session和已产生工具证据。
2. 持久化一个不会显示为普通用户气泡的 interrupted边界，重载时恢复为中断提示。
3. 下一轮模型看到中断语义，旧 todo/readiness不继续阻塞或触发自动重做。
4. 保持现有父取消级联 child、计费 barrier、task Session持久化和前端事件隔离。

## 实现合同

- 移除显式取消路径对 `stripTurnMessagesAfter`的调用，不再截断 Session。
- 在已产生消息之后追加统一的合成中断标记，并立即通过既有 snapshot机制持久化。
- Desktop历史投影把该标记恢复为中断 notice；实时取消后的现有内容保持不变。
- Session preview/turn count忽略合成中断标记，不把它算作用户新 turn。
- `Agent.rebuildTodoState`以中断标记作为 todo边界；重启后不复活中断回合中的未完成 todo。
- 不改变真正 rewind、fork、clear、回收站和永久删除语义。
- 不新增第二份 transcript存储，不复制 child ledger到父 Session。

## 验收标准

- 取消后的内存 Session和落盘 JSONL均含本轮用户、assistant、tool和中断标记。
- 重载历史仍显示本轮内容，中断标记不显示成用户气泡或污染会话标题/turn count。
- 中断前成功的工具结果仍可查看；未闭合工具在历史中为 stopped/interrupted而非成功。
- 旧 todo在中断后和重启后均不进入当前 canonical todo readiness。
- 非用户主动的 timeout、provider错误和内部 context取消不伪造用户中断标记。
- 普通会话和专家团会话均通过停止、切换、重启场景。
