## 实施约束

- 用局部 `.settings-page__header` sticky 规则完成修复；`top: 0` 将页头锚定到滚动容器的 padding edge，由容器自身的响应式顶部内边距保持首屏视觉位置，不再叠加额外偏移。
- 由 `.settings-center__content::before` 提供局部 sticky 顶部遮罩；遮罩高度与最终响应式顶部内边距同步，通过负 margin 抵消布局占位并向上平移覆盖 padding 区，既阻止滚动内容显示和交互，也不移动页头或在首屏遮挡页头前的错误/警告 banner。
- 页头必须提供不透明的 `var(--bg-elev)` 背景与局部抬升层级，防止内容透出。
- 保持现有 margin、padding、边框和 appearance/memory 特化规则，除非为固定行为所必需。
- 测试应解析最终样式源或使用足够具体的契约断言，避免只检查任意字符串存在。
- 修改前检查 `git ls-files --eol`；提交前复核 `git diff --check`、实际 diff、状态和 EOL。

## 验收标准

1. `.settings-page__header` 最终声明包含 `position: sticky`。
2. 页头使用 `top: 0` 锚定滚动容器的 padding edge，由 `.settings-center__content` 的顶部内边距保持首屏位置不变。
3. 响应式规则不再为页头叠加顶部偏移，宽、窄窗口均由各自的内容顶部内边距维持原视觉位置。
4. 滚动容器顶部 padding 区由不透明、可命中的 sticky 遮罩覆盖，滚动内容不能在该区域显示或交互；遮罩不改变首屏页头位置，也不遮挡尚未滚出的错误/警告 banner。
5. 页头和顶部遮罩使用 `var(--bg-elev)` 背景及现有局部抬升 z-index token，滚动内容不可透出。
6. 关闭按钮、导航、嵌入式隐藏页头和错误滚动复位源码保持不变。
7. 扩展的设置导航样式测试通过，`pnpm build` 通过。
8. 实际应用中滚动前后页头标题位置稳定，关闭按钮与左侧导航位置稳定，宽/窄窗口 console 无新增 warning/error。
