# 任务 002：自动化多选与预览移除

## 状态

已完成

## 目标与产物

把连接器和通知目标改为紧凑、可访问的展开式多选控件，并移除新增/编辑页的下三次运行预览及其前端请求。

产物：自动化编辑器 UI、样式、必要的前端桥接清理和聚焦测试。

## 依赖与交付顺序

- 依赖已批准的 `../plan.md`。
- 在任务 001 后串行实施，避免多个写代理修改同一工作树。
- 实现代码和直接相关测试使用独立 `feat:` 提交；验证通过后用独立 `docs:` 提交更新本收据。

## 证据

- 前后端的连接器和通知目标契约均为数组。
- 连接器能力快照已有两个连接器的后端测试。
- 当前 `TaskEditor` 直接把两组目标铺成按钮。
- `schedulePreview` 状态、防抖 effect 和预览 JSX 是页面预览的唯一前端消费方。

## 允许范围

- `desktop/frontend/src/features/automation/heartbeat/HeartbeatPanel.tsx`
- 自动化编辑器直接使用的样式文件
- 直接覆盖本交互的前端测试
- `desktop/frontend/src/features/automation/heartbeat/heartbeat.bridge.ts` 中因预览移除而确定无调用方的包装函数
- 本任务收据

## 禁止范围

- 不改变任务 JSON、Wails 桥接方法签名或后端调度源码。
- 不改技能、专家、模型或工作空间选择器行为。
- 不重构不相关样式或组件。
- 不删除后端 `AutomationValidateDraft` 或 `PreviewNextRuns`。

## 保持行为与约束

- 多选提交继续写入完整数组。
- 不可用连接器不可新增；已保存但不可用的通知目标可移除。
- 结果通知总开关保持显式 opt-in。
- 收起态展示全部选中项，不以数量代替。
- 标签最多三行，溢出时在控件内部纵向滚动；长名称可截断但提供完整标题。
- 复用现有自动化选择器与弹层样式；仅在影响隔离需要时增加局部类。

## 验收标准

- 连接器未选时显示“不使用连接器”。
- 通知关闭时目标多选隐藏；开启后出现，未选显示“请选择通知目标”。
- 两个控件均可展开、复选多个选项并取消选择。
- 所有已选项以标签展示，布局遵守三行溢出规则。
- 页面和源码中不再存在编辑器“下三次运行预览”渲染与草稿防抖请求。
- 后端预览桥接契约和调度函数不变。
- 相关测试与生产构建通过。

- 从 `desktop/frontend` 运行 `pnpm build`。
- 在可用的现实 UI 环境验证展开、复选、隐藏和滚动行为。
