# 自动化多选与通知投递开发计划

## 问题与证据

自动化新增/编辑页把连接器和通知目标直接铺成按钮，选项增多后占用较多纵向空间，且未显式表达两者支持多选。页面还会在每次草稿变化后请求并展示“下三次运行预览”，增加界面信息和持续的桥接调用。

Codegraph 针对索引工作区 `main-v3`、基线 `b30b5ce274f50eacd1bb9460bf8ae1a529d75886` 的调查，以及同一基线上的直接源码核对，确认：

- `CapabilitySelection.ConnectorIDs` 是数组；能力快照逐个解析全部连接器、合并工具白名单和授权元数据，运行器把全部连接器 ID 与合并后的工具白名单传给控制器。
- `TestResolveCapabilitySnapshotDeduplicatesTools` 已覆盖两个连接器的工具合并与去重。
- `DeliveryPolicy.Targets` 是数组；规范化和校验遍历全部目标，运行结束后 `enqueueRunDeliveries` 逐个创建投递尝试。
- 当前投递循环在任一目标发送失败时立即返回，导致后续目标没有机会发送；现有测试没有覆盖两个通知目标。
- `TaskEditor` 中的 `schedulePreview` 状态、防抖 effect 和预览区域是“下三次运行预览”的唯一前端消费方。
- 后端 `AutomationValidateDraft` 是已导出的桌面桥接契约，`PreviewNextRuns` 还被调度服务消费；删除后端链路风险大于隐藏页面所需范围。

调查时运行的聚焦测试：

```powershell
go test ./internal/automation -run 'TestResolveCapabilitySnapshotDeduplicatesTools|TestEngine.*Delivery|TestNormalizeTaskV2CompatibilityFields'
```

结果通过。

## 目标

- 连接器改为点击展开的多选复选框，保留真实多连接器语义。
- 通知目标在开启结果通知后显示为点击展开的多选复选框。
- 收起态直接展示所有已选项，不使用仅显示数量的摘要。
- 已选项自动换行，最多三行；超过后在控件内部纵向滚动。
- 空连接器选择明确显示“不使用连接器”；关闭结果通知时隐藏通知目标选择框。
- 一个通知目标投递失败时，仍尝试其余目标，并返回聚合后的错误。
- 移除新增/编辑页的“下三次运行预览”及其前端请求，不破坏后端调度能力和公开桥接契约。

## 非目标

- 不改变自动化任务 JSON、Wails 方法签名或持久化格式。
- 不改变连接器授权、安装、凭据或工具注册流程。
- 不改变通知目标目录、目标引用格式、凭据解析或重试模型。
- 不删除 `AutomationValidateDraft`、`PreviewNextRuns` 或后端调度预览能力。
- 不重构自动化编辑器的其他选择控件。

## 交互与行为

### 连接器

- 字段保持可选。
- 未选择时触发器显示“不使用连接器”。
- 点击触发器展开复选框列表；不可用连接器不可选择并保留原因提示。
- 已选项以独立标签全部显示；标签换行，内容区最多三行并允许纵向滚动。

### 结果通知

- “任务完成后推送结果”开关保持默认关闭。
- 关闭时不显示通知目标选择器。
- 开启后显示多选触发器；未选时显示“请选择通知目标”并保留现有校验提示。
- 已选目标同样以标签全部显示并使用三行溢出规则。
- 已保存但当前不可用的目标仍可见且可移除，不能重新添加不可用目标。

### 多目标投递

- 每个目标继续拥有独立投递尝试和事件。
- 某目标失败不阻断后续目标。
- 所有目标处理完成后返回聚合错误，使运行记录继续反映投递失败，而不是静默吞错。

### 运行预览

- 删除 `TaskEditor` 的预览状态、防抖调用和预览 JSX。
- 若前端桥接包装函数因此无调用方，则删除该未使用包装和导入。
- 保留后端导出方法与核心调度函数，避免扩大兼容性风险。

## 兼容性与迁移

任务数据仍保存完整的 `connectorIds` 和 `delivery.targets` 数组，旧任务无需迁移。通知开关关闭时，桥接层保持现有行为：提交时不发送目标。后端投递错误仍会上报，只改变后续目标是否继续尝试。

## 风险与缓解

- **多选弹层键盘可访问性退化**：使用明确的复选框、可聚焦选项、`aria-expanded` 和可识别的字段标签，并补充聚焦测试。
- **大量标签撑高表单**：限制为三行并在标签容器内部滚动；单项过长时截断并保留完整 `title`。
- **聚合错误改变错误文本**：仅依赖非空错误语义，不引入新的持久化字段；测试验证所有目标均被尝试及最终错误存在。
- **预览删除误伤校验**：保存仍由创建/更新后端规范化和校验；保留后端验证契约。构建和聚焦测试验证没有残留引用。

## 回滚

前端多选、预览 UI 移除和后端失败隔离按独立实现提交交付，可分别回滚。数据契约不变，因此回滚不需要迁移。

## 验收标准

- 连接器和通知目标均能选择、取消选择多个有效选项，提交后数组完整保留。
- 未选连接器显示“不使用连接器”。
- 结果通知关闭时不显示目标选择器；开启后未选显示“请选择通知目标”。
- 收起态显示每个已选标签；标签最多占三行，超出可在控件内滚动。
- 不可用的已保存通知目标仍能被移除。
- 两个通知目标中第一个失败时，第二个仍被投递；方法最终返回失败。
- 页面不再渲染“下三次运行预览”，草稿变化不再触发其前端验证请求。
- 后端 `AutomationValidateDraft` 和 `PreviewNextRuns` 保留。
