预期产物：

- 一份由生产源码导出的候选 emitter 清单，明确纳入、排除和动态参数边界；
- 一个无 React 状态、无网络和无存储副作用的展示映射模块；
- 复用 `desktop/frontend/src/locales/zh.ts` 的中文文案；
- 覆盖全部规则、相似未命中和未知 identity 的自动化测试。

## 必须保留的行为

- 未命中规则逐字返回输入文本，包括空白和第三方错误细节。
- 动态错误只翻译稳定前后缀，外部 `err.Error()` 内容不得丢失。
- Phase 保留模型名或任务树上下文，只转换已知阶段含义。
- 同一英文短语出现在模型正文或工具输出时不应被调用此映射。
- 现有用户取消、retry 和 compaction locale 不改名、不迁移。

## 实现约束

1. 先用 `rg` 从生产文件列出 Notice/Phase emitter，排除 `*_test.go`、CLI、ACP 和 automation 专用路径，再定义规则。
2. 规则以事件展示类别隔离；静态文本精确匹配，动态文本使用完整锚定正则或稳定前缀。
3. 不允许宽泛 `includes`、语言检测或“未知错误”替换。
4. 映射模块接收 translator 或返回稳定 locale key/params，不直接硬编码散落中文。
5. task 可见文案不含内部 ID；原始文本不由本模块修改。
6. 清单和测试必须一一对应，使新增或删除规则可审计。

## 验收标准

1. 生产 emitter 候选已完成分类，所有纳入规则均有来源和测试。
2. Agent、压缩、Phase、持久 task 及确认可见的 boot/control/profile/plugin/Desktop Notice 均有保守规则或明确原样理由。
3. `model · planning/executing` 和 `task_tree:*` 保留上下文并显示中文阶段。
4. task finished/failed/killed/stalled 显示可区分的中文且不含内部 ID。
5. 未知和相似未命中文本逐字不变；动态错误详情不丢失。
6. 模块没有 React、存储、网络、运行时协议和生产 Go 依赖。
