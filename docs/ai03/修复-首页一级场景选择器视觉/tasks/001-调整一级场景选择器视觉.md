# 001 调整首页场景选择器视觉

## 目标与产物

将首页一级场景选择器改为主题化胶囊控件，并统一二级场景按钮的胶囊轮廓；产物包括局部 CSS、样式契约测试和本任务完成收据。

## 允许范围

- `desktop/frontend/src/styles/theme-overrides.css`
- `desktop/frontend/src/__tests__/workbuddy-creation-theme.test.ts`
- 本修复目录文档

## 禁止范围

- 场景切换、会话状态、持久化和导航逻辑
- 全局主题令牌与其他页面控件
- transform、filter、box-shadow、will-change 等高成本悬浮效果

## 验收

- 外层无中性灰边框，使用极浅主题色轨道。
- active 使用 `accent`/`accent-fg`，未选中项透明。
- hover/focus-visible 使用浅主题色且无位移、滤镜和阴影。
- 二级场景按钮、“更多”及展开项使用一致的 `999px` 胶囊圆角，原有颜色与状态规则不变。
- 原有场景切换测试、主题契约测试和前端构建通过。
