# 002：恢复已有会话首帧呈现

## 任务目标

使用任务 001 补齐的目标会话身份和既有内存视图快照，在标签切换、历史重开和重启恢复时
立即呈现目标会话的模型/推理强度；后端激活前保持可见但禁用，并继续使用现有权威回读、
权限门禁和竞态保护。

## 预期产物

- 冷状态和 `SessionViewSnapshot` 能恢复一个目标会话的确认展示组合。
- surface transition、目录/权限 loading 不再无条件把可靠目标快照清成 pending 加载壳。
- definitive entitlement denial 仍进入现有 `choose`/“请选择模型”。
- 主动模型切换、强度乐观更新、失败恢复和 degraded 行为不变。
- 三种已有会话入口、快速切换和权限状态均有自动化回归覆盖。

- 依赖任务 `001-补齐会话强度快照合同.md` 的已审查提交。

## 保留行为与约束

- 只有与目标 session identity 匹配的快照可以首帧显示。
- 激活未完成时 Composer 整体沿用现有禁用保护；不得允许写入错误 tab。
- 没有可靠 effort 快照时不伪造强度，继续等待权威结果。
- 权威刷新继续使用每标签单调 seq；旧请求必须被拒绝。
- 用户主动选择模型时继续显示上一确认组合直到新组合 ready。
- 用户主动选择强度时继续立即显示新强度，失败恢复旧组合。

## 验收标准

- 已打开标签切换首帧显示目标模型/强度，无空白、loading 或跨会话混配。
- 历史会话重开使用 session identity 首帧显示；重启恢复在 tab meta 到达后一次显示。
- subscription loading 显示持久化组合并禁用；最终 unavailable/denied 显示“请选择模型”。
- BYOK 目录 loading 不清空持久化组合。
- 不支持 effort 的模型只显示模型。
- 快速 A→B→C 切换时 A/B 的迟到结果不能覆盖 C。
- 主动模型/强度切换的 PR #351 回归测试保持通过。

## 完成回执

### 状态与改动文件

已完成。冷状态和首次 `ListTabs`/标签切换会把目标 identity 的模型及可选 effort 种入现有
`composerSelection`；`SessionViewSnapshot` 版本升级并保存已确认的 `EffortInfo` 与组合状态。
可靠快照在 surface transition、目录或 entitlement `pending` 时保持可见且 busy，最终
entitlement `choose` 仍优先显示“请选择模型”。display-only effort 只显示持久化字符串，
不会构造 supported/default/levels，也不会开放强度选项。
