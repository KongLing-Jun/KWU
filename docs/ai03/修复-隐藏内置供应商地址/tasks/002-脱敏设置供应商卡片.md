## 状态

- 状态：completed，代码与聚焦验证已完成。

## 目标

让 Wails 设置数据和前端生产包不再暴露内置 AirClaude API 基址，同时保留内置卡片、登录动态模型、刷新功能和所有自定义 provider 的地址展示与编辑能力。

- `desktop/frontend/src/features/settings/ui/ModelsSettingsSection.tsx` 当前渲染 `group.baseUrl`，并把缺少 `baseUrl` 作为刷新按钮禁用条件之一。

## 交付物

1. 官方 `ProviderView.BaseURL` 在所有 Settings/SettingsModelDetails 返回路径中为空。
2. 设置详情中的动态账号目录只进入独立官方卡片；普通 provider 列表过滤精确官方条目并保留同名不同地址的自定义项。
3. 后端装饰器只锁定 `BuiltIn && Name == kwu` 的条目；同名自定义项保持 BYOK、可编辑和可见地址。
4. 前端删除官方现网/历史 API 基址常量，不再依赖 URL 识别内置卡片。
5. 内置卡片不显示地址但刷新仍可用；自定义卡片保持现有地址、配置、刷新和删除行为。
6. 相邻 Desktop Go、前端测试、生产构建及任务完成回执。

## 禁止范围

- 不修改配置版本、TOML 渲染、升级迁移、默认模型或 Desktop 订阅目录状态机。
- 不修改登录、凭据、账号、套餐、模型商城或实际模型调用。
- 不删除内置卡片，不改变卡片名称、排序、套餐标签或模型列表筛选。
- 不移除 `ProviderView.BaseURL` JSON 字段，不进行 Wails 公共合同重构；内置值为空即可。
- 不隐藏自定义 provider 地址，不把任意名为 `kwu` 的自定义 provider 锁定为内置。
- 不通过混淆、编码或运行时拼接把敏感 URL 留在前端。
- 不改公开模型商城价格来源 URL。
- 不委派、不推送、不创建 PR。

## 必须保持的行为

- 未登录时内置卡片继续显示既有 `signed_out` 状态和空模型目录。
- 已登录授权目录 ready 时，内置卡片继续显示账号动态模型和已配置状态。
- 内置刷新按钮继续调用既有专用官方刷新方法，并保留 loading/error/success 状态。
- 自定义 provider 继续按现有校验要求使用 `baseUrl`，其刷新按钮仍可因地址缺失而禁用。
- 同名不同地址的 `kwu` 自定义项仍出现在普通 provider 列表，显示地址并标记 BYOK；不与独立官方卡片合并。
- Settings 兼容聚合接口与 SettingsModelDetails 返回相同脱敏语义。
- `officialProviders` 与 `providers` 在前端形成明确的展示/选择合并视图，但原始自定义 `providers` 仍是编辑、删除和 provider 数量的权威。

## 实现约束

1. 先复述目标、证据、允许范围、保持和禁止行为；若需要改变 Wails DTO 形状或登录目录状态机，停止并升级给主 Agent。
2. 后端必须先判定 `BuiltIn` 再清空地址；清空后不能再依赖地址完成分类。
3. `settingsModelDetailsFromConfig` 不得为了官方动态目录修改可编辑 provider 配置；官方模型直接由既有订阅状态装饰官方卡片。
4. 普通 provider 列表过滤使用 Task 001 的精确官方定义，不能仅按名称过滤。
5. `SettingsPanel` 必须把官方/自定义视图显式合并后交给卡片和模型候选；不能只修改后端数组而遗漏现有 `s.providers` 消费者。
6. 模型候选以 `ref + billingSource` 为身份。官方与同名自定义项产生两条路由，订阅访问过滤按路由来源选择对应 provider，不能再要求 provider name 唯一。
7. 前端内置判定必须基于后端元数据；provider ID 只用于品牌映射，不能单独把自定义项升级为内置。
8. 刷新按钮条件必须区分 locked official 和 custom，避免空地址让官方刷新不可用。
9. 测试夹具使用空地址或无关示例地址，不得把敏感 URL 留在前端测试源码。
10. 每个代码提交使用 `<English type>:<Chinese description>`；代码提交与任务回执提交分开。

- 完整设置页 fixture 中 `officialProviders` 仅含内置 `kwu`、`providers` 仅含同名自定义 `kwu` 时，两张卡片均显示；前者无地址且可刷新，后者有地址且可编辑。
- 上述 fixture 的相同 `kwu/model` 生成 subscription 与 BYOK 两条模型路由；订阅权限变化只过滤 subscription 路由，BYOK 路由保持。
- Task 001 的根默认、迁移和四模型兜底测试继续通过。
