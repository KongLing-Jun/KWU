# Task 001：将官方供应商改为运行时配置

## 状态

- 状态：completed（Desktop 回归与复杂度门禁均已闭合；Task 002 保留其独立回执边界）。

## 目标

让内置 AirClaude provider 不再进入 TOML，同时保持 Desktop `subscription_pool` 在磁盘配置没有官方 provider 时仍能构造可用的运行时 provider；把根默认模型改为 `kwu/deepseek-v4-flash`，并对版本 3 用户配置执行一次精确迁移。

## 必须保持的行为

- 精确官方判定继续接受 endpoint 等价形式（如尾斜杠），不退化成 host-only 或 name-only 判定。
- TOML 只声明其他名称的自定义 provider 时，通用 Load 后根 Flash 默认仍可解析；该兼容合同适用于共享配置/CLI，不只适用于 Desktop。
- DeepSeek、MiMo 等其他官方 provider 的渲染、价格升级和 provider access 规范化不变。
- 损坏 TOML 不覆盖；不存在的用户配置不因升级入口而创建。
- `LoadForEditWithoutCredentials` 继续不读取或水合 provider 凭据。
- 目录为空时现有失败关闭分支保持为空；只有既有显式静态兜底入口使用四模型。
- 动态目录不含 Flash 时继续回退到首个可用模型；包含 Flash 时 provider 默认保持 Flash。
- 显式 BYOK 路由仍读取用户 provider；订阅注入只修改调用方拥有的内存配置副本。
- 无活动会话时 effort 保持 `auto`，不再把非默认 effort 写入官方 provider 块；实际前端使用的带 `tabId` 会话级 effort 选择和恢复行为保持不变。

## 实现约束

1. 先复述目标、证据、允许范围、保持和禁止行为；有任何会扩大配置迁移或改变目录失败语义的歧义必须停止。
2. 使用同一个精确官方谓词驱动渲染过滤和迁移删除；不得复制不同匹配逻辑。
3. TOML 过滤不得原地修改调用者 `Config`，否则设置页和运行时可能观察到持久化副作用。
4. 升级判断必须读取原始 header 的 provider/default 证据，再通过无凭据 edit loader 修改；加载后的默认补全不能作为“用户原文件含官方条目”的证据。
5. 原文件同时含精确官方和同名自定义 `kwu` 时：删除官方，保留自定义，根 `kwu/gpt-5.4` 不迁移。
6. 订阅 upsert 必须从官方模板重新建立 endpoint、key env 和运行时元数据；不得继承同名自定义 provider 的地址或凭据字段。
7. 现有 `applyDesktopSubscriptionCatalog` 的授权空目录语义不变；upsert 时点不得把失败关闭变成静态兜底。
8. 通用 loader 只在当前配置存在 `kwu` 模型引用且 provider 列表没有任何同名项时物化官方模板；不覆盖同名自定义 provider，不写回 TOML。
9. `Load`/`LoadForRoot` 的 `mergeTOMLProviders` 路径和 edit loader 的 `replaceProvidersFromExistingEditFile` 路径必须调用同一个 helper，不能只修其中一条。
10. real 与 fake/fixture 的显式 `subscription_pool` 配置都必须可从不含官方 provider 的磁盘输入构造运行时条目；fake 目录和网关仍由既有 fixture 负责。
11. 每个代码提交使用 `<English type>:<Chinese description>`；代码提交与任务回执提交分开。

- `Default().DefaultModel == "kwu/deepseek-v4-flash"` 且 `ResolveModel` 成功。

- 三种 render scope 对现网/历史官方条目零输出，对同名自定义条目完整输出。
- 版本 3 官方配置迁移后不含官方 provider/endpoint，根默认为 Flash，其他 provider 和非根模型引用字节语义等价。
- 版本 3 同名混合配置只删除官方条目，不迁移根默认，不修改自定义条目。
- 第二次迁移返回未变化且文件内容不变；损坏文件返回错误且内容不变；不存在文件不创建。
- 升级测试证明只接收用户配置路径，没有登录/凭据路径参数或文件操作。
- 磁盘无官方 provider 时，订阅配置副本可解析动态模型和静态目录；BYOK 副本保持原用户 provider。
- TOML 只含其他名称自定义 provider 时，通用 Load 后根 Flash 默认可解析，再次保存仍不输出官方块。
- `Load`/`LoadForRoot` 与 `LoadForEditWithoutCredentials` 两类往返各自覆盖上一条验收，不允许用一个 loader 的测试替代另一个。
- real 和 fake/fixture 订阅构造都不依赖 TOML 残留官方块。
- 目录空授权分支仍为空，四模型兜底测试精确通过。
- 相关现有 config/desktop 路由测试没有因默认值变化之外的行为回归。
- 无活动会话的 effort 测试验证默认 `auto` 且 TOML 不出现官方 provider、官方 endpoint 或新增 effort 字段；现有会话级 effort 测试继续通过。
