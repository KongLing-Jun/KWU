## 已确认决策与证据

- 专家标签切换能力面板；独立 `×` 才取消专家。
- 第二次点击标签、点击外部或按 `Esc` 关闭面板。
- 只修专家标签被误判为外部点击，不改变样式、协议或其他入口。
- 当前弹层只认“＋”按钮为 anchor；专家标签打开后，同一次 document click 触发外部
  关闭，是闪关的直接原因。
- 采用现有意图控制组作为共享锚点，不扩展通用弹层 API。
- 当前回归测试覆盖“＋”和 `×`，缺少专家标签开关路径。
- 未修代码的真实浏览器回归稳定失败于 `aria-expanded=false`；修复后目标用例及完整
  browser smoke 通过。
- 最小实现仅把既有意图控制组设为共享 anchor；未改通用弹层 API、CSS、专家状态或
  取消逻辑。
- 内置浏览器已验证首次打开、当前专家选中、二次点击/外部点击/`Esc` 关闭和独立
  `×` 清除，控制台无 warn/error。
- 项目 common checks 与完整 PR Gate 通过；路径分类只要求 frontend production build，
  Root Go 与 Desktop Go 均为 none。
- 用户在实际 Wails 小窗口复核时发现，现有 `calc(100vh - 24px)` 高度使能力面板几乎
  遮住全部页面；已确认改为约 70vw × 65vh 的紧凑双栏浮层并在栏内滚动。
- 实际 Wails 小窗口已热更新并由用户确认效果可以；900×620 尺寸回归和完整浏览器
  smoke 8/8 通过，Composer 回归 41/41 与生产构建通过。
- 小屏补丁提交后的 common checks 与完整 PR Gate 通过；仍只分类为 frontend build，
  Root Go 与 Desktop Go 均为 none。
