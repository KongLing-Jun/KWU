## 目标与预期产物

按照 [`../plan.md`](../plan.md) 实现统一账户头像规则：

- 当前身份槽位有本地手选图片时显示该图片；
- 没有本地图片时显示实心 `brand-symbol.png`；
- 未登录使用 `local` 槽位，可恢复账号使用稳定 `cloud_user_id` 槽位；
- 切换或退出后的首次渲染不携带上一身份图片。

产物是一组可独立验证、合并和回滚的桌面前端代码与测试，以及本文件更新后的完成回执。

## 保持行为与约束

- 保持 `clouvia.sidebar-avatar.local` 和
  `clouvia.sidebar-avatar.<cloud_user_id>` 键格式及既有数据可读。
- 不使用 `display_name` 标识账号；无稳定 ID 时使用 `local`。
- `authenticated` 以及带 ID 的 `offline`/`expired` 使用账号槽位，其他状态使用 `local`。
- 品牌图标只作渲染回退，不写入本地存储。
- 本地图片必须与其已加载存储键一起保存；当前键不匹配时立即显示品牌图标，禁止旧图片进入新身份首次渲染。
- 上传完成只更新当前键；PNG/JPEG/WebP、2 MiB 限制和错误提示不变。
- 账户文字、无障碍名称、菜单操作、登录/切换/退出业务不变。
- 未登录账户中心不新增身份卡；标题和操作菜单功能图标不属于头像。

## 实施步骤

1. 在 `useAccountSidebar` 中集中解析当前头像存储键。
2. 将头像状态改为“已加载键 + 图片值”，并派生只属于当前键的安全图片值。
3. 保持本地读取失败为空值；上传成功后原子更新当前键和值。
4. 在 `App.tsx` 统一解析本地图片或实心品牌图标，移除首字符头像参数和计算。
5. 在 `AccountCenter` 已登录身份卡中使用相同默认图标，保留其他 `UserRound` 功能图标。
6. 增加聚焦测试，完成真实应用视觉与状态验收。
