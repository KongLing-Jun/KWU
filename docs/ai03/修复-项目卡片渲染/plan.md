# 项目页卡片渲染兼容修复计划

## 问题与证据

消息通道卡片已证明，低性能 Windows/WebView2 环境可能在大面积卡片悬浮重绘时出现
矩形色块。项目页的“最近项目”和“快速开始模板”卡片采用相同触发方式：悬浮时同时
切换背景并执行 `translateY(-1px)` 过渡。

Codegraph 将两类卡片定位到 `ProjectDirectory`；最新 worktree 源码确认其样式集中在
`features.css`。现有项目页测试覆盖加载、搜索、点击和模板选择，但没有限制高重绘的
悬浮效果。

## 目标与边界

- 同时兼容项目页的最近项目卡片与快速开始模板卡片。
- 保留点击、搜索、禁用加载、当前项目状态和键盘操作。
- 仅处理项目页，不修改消息通道、其他页面或全局卡片规则。
- 不引入 `will-change`、`translateZ(0)` 或 WebView2 全局硬件加速开关。

## 方案与验收

- 两类卡片取消过渡、位移和悬浮背景切换，仅保留边框反馈。
- 内部图标和箭头保持静态，当前项目继续使用常驻选中背景。
- 焦点使用 `outline`，不使用阴影。
- CSS 契约测试阻止重新引入背景、transform、阴影、滤镜、透明度或动画。
- 聚焦测试、前端构建通过，并由可复现环境确认页面视觉可接受。

本修复无数据迁移；若视觉取舍不可接受，可整体回滚项目页 CSS 和对应契约测试。
