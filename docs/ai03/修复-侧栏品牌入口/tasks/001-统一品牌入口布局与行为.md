# 001 统一品牌入口布局与行为

## 目标与产物

调整 Windows 创作模式侧栏品牌区位置，增加动态版本与可访问的新建会话入口，并以源码契约测试固定行为。

## 依赖与证据

- 依赖既有 `App.handleNewTab()` 与 `app.Version()`，不修改其契约。
- `App.tsx` 当前品牌文本、历史按钮、收起按钮位于同一品牌容器。
- `theme-overrides.css` 当前创作模式侧栏顶部 padding 为 `38px`。

## 允许范围

- `desktop/frontend/src/App.tsx`
- `desktop/frontend/src/lib/brand.ts`
- `desktop/frontend/src/styles/theme-overrides.css`
- 最近相关的 `desktop/frontend/src/__tests__` 契约测试
- 本任务文档和 `progress.md`

## 禁止范围与保留行为

- 不修改后端、桥接接口、会话控制器或其他布局模式。
- 不改变历史、侧栏收起、新建会话的既有处理器语义。
- 不使用 transform、filter、阴影、动画或 transition 实现布局和反馈。

## 验收与验证

- [x] Windows-only `0` 顶部间距、`72px` 品牌行与入口高度、`0` 底部 margin，其他平台顶部间距保持 `38px`。
- [x] Windows 创作模式品牌名使用 `16px` 字号，保留现有字重、版本行和居中关系。
- [x] 动态版本保证单一 `v` 前缀；失败/空值不渲染占位。
- [x] 品牌按钮直接调用 `handleNewTab()`，工具按钮保持独立兄弟节点。
- [x] 无嵌套按钮及高开销视觉属性。
- [x] 品牌按钮默认、悬浮和按下状态透明，键盘焦点轮廓保留。
- [x] 最近相关测试通过。
- [x] `pnpm build` 通过。
- [x] EOL、状态、完整 diff 与 `git diff --check` 已检查。
