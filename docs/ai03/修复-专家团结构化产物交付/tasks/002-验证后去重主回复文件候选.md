## 实现约束与验收

1. 校验前仅按 `displayAttachmentPathKey` 的完整精确键去重。
2. 验证成功集合只记录实际成功候选的精确键，不能以等价候选代替成功。
3. 渲染成功附件时继续按既有绝对/相对等价规则去重。
4. 错误绝对路径 + 有效相对路径：两次验证、一张相对路径卡片、点击打开成功。
5. 两者都有效：一张卡片；两者都失败：零卡片且无坏链接。
