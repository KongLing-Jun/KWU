## 目标与产物

显式产物子任务只有在宿主检测到的本轮工作区文件满足完整 `ArtifactRequirement.Targets` 时才能成功。
空产物、错误路径、错误类型、目标数量不足和只读旧文件均返回失败；匹配产物继续走现有结构化回传。

1. 预置 `snake.html`，子专家只调用 `read_file` 后声称完成，现有代码仍返回成功终态。
2. 要求明确路径/类型/两个不同产物，但只写错误或不足文件，现有代码仍返回成功。

## 实现约束与验收

1. handoff 初始化时只解析一次并保存完整 `ArtifactRequirement`。
2. 子会话无其他错误时，使用宿主检测文件的规范路径匹配每个 target，且一个文件不能满足多个目标。
3. 不匹配返回明确错误并通过现有持久化/A2A 路径形成失败态；失败不得写入完成态 `TurnArtifacts`。
4. 匹配函数与最终 evidence 使用同一规范化、路径后缀、扩展名、排除项和数量语义。
5. 测试不得以“贪吃蛇”白名单通过；核心回归使用明确 `snake.html` 子任务合同。
