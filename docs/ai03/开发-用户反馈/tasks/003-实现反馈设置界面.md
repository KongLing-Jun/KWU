## 实现约束

1. 创作型账户菜单在“外观”后、“退出”前增加始终可见的“帮助与反馈”，点击
   关闭菜单并将 `settingsTarget` 设为 `feedback`。
2. 设置导航末尾增加“支持”分组及“帮助与反馈”；右侧直接渲染表单。
3. 从账户初始化、云可用性、账号 status 和 recoverable identity 单独推导反馈
   登录状态；不得因无套餐或订阅模型不可用而阻止反馈。
4. 未登录/失效时禁用表单，显示中文说明和“去登录”；调用前先执行反馈 dirty/
   submitting guard，再走既有 `openAccountCenter`。
5. 草稿 owner 存活于整个 SettingsPanel；切换设置标签不丢文字、图片、错误后的
   attempt ID 或令牌。关闭设置、去登录或账号 scope 改变时按方案确认并释放。
6. 描述 trim 后至少 1 个、最多 300 个 Unicode code point（前端用
   `Array.from`，与后端 `utf8.RuneCountInString` 一致），并用 `TextEncoder`
   防御 10,000 UTF-8 bytes；显示计数，不展示服务端不接收的字段。
7. 图片按钮调用原生 picker；最多 4 张，展示安全缩略图、文件名、大小和删除；
   页面只提示“请勿上传包含敏感信息的图片”。
8. 首次提交用 `crypto.randomUUID()` 创建 attempt ID；失败且内容未改时沿用，
   任意文字/图片变化立即清除；不得自动重试。
9. 提交中禁用表单、导航退出、关闭按钮、Esc、遮罩、去登录和重复提交，显示
   “正在提交”；结束或 120 秒超时后恢复。
10. 成功或 `replayed=true` 清空草稿并显示可复制 `report_id`；失败保留草稿，
    显示结构化中文 message、错误码和可复制 request ID，不解析 Wails 错误字符串。
11. 样式复用现有设置 token，覆盖明暗主题、键盘焦点、窄窗口和 reduced motion。

## 验收标准

- 入口位置、设置分组、直达标签和创作型限定符合方案；其他布局无新增入口。
- 匿名、过期、无套餐但已认证、真实已认证四种状态的表单权限正确。
- 纯文字、单图、多图分别调用一次正确 bridge；非法/超限内容不提交。
- 图片清晰、可删除；前端 DOM、状态和错误不含本地路径或原图。
- 切标签保留草稿；有内容关闭会确认；提交中所有退出路径均被拦截。
- 失败保留并同键重试，编辑后换键；成功和 replayed 成功清空并显示报告 ID。
- 全部用户可见错误为中文；没有英文 fallback、日志上传或额外字段。
