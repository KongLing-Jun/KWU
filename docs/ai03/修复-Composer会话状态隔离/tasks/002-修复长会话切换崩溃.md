# 任务 002：修复长会话切换崩溃

- 状态：已完成。
- 执行组：Serial-02；依赖已完成的任务 001。
- 交付切片：会话切换原子呈现与折叠工具详情惰性挂载。

- 指派：当前主会话，不委派子代理。

## 目标与证据

保持任务 001 的 Composer 会话隔离，同时消除工具密集长会话反复切换导致的
WebView2 `STATUS_BREAKPOINT`。真实应用证据：短会话 12 轮切换稳定；长会话约
8 轮复现崩溃；一次长会话往返后渲染进程工作集增长约 28 MB。

源码已证明折叠 `ToolCard` 仍创建 `CodeViewer`、`DiffView` 与嵌套工具 DOM，
而 surface transition 在目标快照和旧 `activeTab` 之间形成非原子呈现。

## 允许与禁止范围

允许修改 `ToolCard`、会话 surface transition/App 呈现、直接相邻前端测试、
本任务回执与进度文档。禁止修改任务 001 的后端持久化契约、历史数据、模型
fallback、网络接口、依赖与 code guard baseline；不得删除或截断历史内容。

## 必须保留的行为

- 工具卡标题、摘要、状态、媒体预览及展开后的完整内容不变。
- 运行中的 shell/subagent 仍可自动展开，归档详情仍按需加载。
- 会话滚动锚点、历史分页、消息操作和任务 001 的模型/来源/强度隔离不回归。
- 切换未完成时不能把操作发送到来源会话或展示可操作的错误模型身份。

## 验收与验证

1. 已完成且折叠的普通工具不挂载详情 DOM；首次展开内容完整，关闭动画后释放。
2. 运行态、媒体、归档详情失败、嵌套工具和 diff 行为通过相邻测试。
3. 切换过渡期标题、正文和 Composer 身份一致，交互被正确门禁。
4. 前端聚焦测试与 `pnpm build` 通过。
5. 真实应用执行短/长会话往返至少 20 轮，无白屏、崩溃或身份串用；记录切换
   前后及空闲 12 秒后的渲染进程工作集。
6. `go run ./scripts/code_guard`、`git diff --check` 与 EOL 检查通过。
