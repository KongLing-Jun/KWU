## 目标与交付物

## 实现合同

### 映射与 DOM

- 模块级导出纯函数，由 `variant/scene/sceneState` 派生结果；仅
  `creation + locked + office|coding|design` 返回短标签 key、完整说明 key 和
  同名 tone，其余返回 `null`。不得使用会默认到办公的 normalize helper。
- 每个节点只读自身场景。在 `project-tree__topic-heading` 内、标题之前用显式
  `presentation ? … : null` 渲染，不产生占位。
- 可见文本仅 `办公/开发/设计`，不可点击或聚焦；`title` 提供完整说明，屏幕阅读器
  也必须获得例如“场景：日常办公”的完整文本，不能只依赖 `title` 或伪造交互 role。

### 样式与文案

- 使用基础 class 与三个 tone modifier，全部受 `.app--creation` 约束；禁止内联色。
- 标签 `flex: 0 0 auto`、单行且不撑高 23px 行；标题仍省略，右侧时间、状态点、
  hover/focus 菜单和 action 定位不变。
- 基于现有主题变量与 `color-mix` 提供低饱和暖灰、蓝灰、紫灰，浅/深主题可读。
- 在 `projectTree` 命名空间加入短标签和完整说明；当前仅简体中文，不新建英文 locale。

## 必须保留的行为

- draft、legacy、缺失、空值、非法值及 classic/workbench 均无标签、无占位。
- 父主题和展开子会话按各自场景显示；不得从 active tab、父节点或最近节点继承。
- 长标题省略、时间和 actions 时序、重命名/菜单、active/running marker、来源 chip、
  搜索与快捷键徽标保持现状。
- 首次回合完成后沿用现有树刷新；重启恢复时只按已持久化的 locked 真值显示。
