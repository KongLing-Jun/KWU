## 原生验收步骤

1. 从 clean 精确 HEAD 构建带 DEV transcript trace 的 Wails Desktop，记录 HEAD、进程与证据目录。
2. 长专家会话明确 bottom 后只执行一次向上 wheel，等待稳定并记录 opaque identity、index、offset、截图。
3. 打开模型广场确认 Transcript 卸载，再返回同一已选专家会话；核对该返回内 cache miss、写入和 hit。
4. 核对 pending 期间无可见 legacy，persisted 稳定前不可见且最终只揭示一次。
5. 核对 `viewport.visible-jump=0`、virtual seek `≤1`、completion `stable`、identity 相同；offset 可达时
   误差 `≤8px`，不可达时停在 signed correction 指向的最近物理边界且 canonical 不变；无 bottom fallback、
   第二次 wheel、崩溃或错误 cache write。
6. 用足够长的普通聊天执行相同中部返回，证明共享 restore 无可见跳动和重复 seek。
7. 保存最小结构化事件、截图、可访问树与文件哈希；不复制私密正文或大日志入仓库。
