## 实现约束

1. persisted team 未定案为 pending；ready 后只显示 `ExpertTeamSessionView`；缺失/读取失败显式 error/retry，
   不显示 legacy fallback。
2. next expert state 必须先完成 sidecar 原子保存，再提交 controller/executor；失败返回错误且原状态不变。
3. 每个 restore generation 最多一次 virtual seek；取得 DOM measurement 或可解析 row geometry 后，即使 DOM
   离开 overscan，也只用 virtual visual offset + saved offset 纠偏。
4. 稳定允许 DOM 或虚拟几何证明，要求 identity/row 有效、正常可达时误差 `≤1px`、layout revision 连续稳定；
   保存 offset 物理不可达时，仅可信 measured virtual geometry、signed correction 指向已抵达边界且连续稳定
   30 帧可按 closest clamp 完成，不改 canonical/bottom/seek；其他 incomplete 不能揭示或写漂移 cache。
5. persisted workspace 稳定前参与真实布局但不可见、不可交互、`aria-hidden`；不能用 `display:none`。
6. 用户输入、reveal、跨 view、卸载与 aborted render 保持 committed ownership，旧 RAF/sidecar result 不重放。

## 验收标准

- tabId-less/cache miss 不出现可见 legacy；ready 后只有 persisted 且只揭示一次。
- offscreen anchor seek `≤1`，DOM 正常卸载后仍稳定到原 identity/offset，不以 incomplete 结束。
- sidecar 保存失败对调用方可见，controller/executor/原选择不变；重试成功后可重入读取。
- 普通长 Transcript 同样不重复 seek；普通短聊天、true bottom、用户滚动和既有 fallback 不回归。
- DEV trace 不包含正文；生产 bundle 不启用诊断。
- diff 仅限允许范围，任务回执、LF EOL、status 与 commits 一致。
