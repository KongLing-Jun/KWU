# 任务 001：对齐 WorkBuddy 专家页并降低渲染开销

## 目标与产物

在不改变专家页数据和业务流程的前提下，将精选场景、专家/专家团网格及目录卡片对齐 WorkBuddy 的紧凑视觉，并移除低性能 WebView2 设备上风险较高的整卡合成效果。

产物包括专家页 CSS、样式契约测试、任务完成回执和可供用户验收的本地页面。

## 禁止范围与保留行为

- 不修改 React 组件结构、专家数据、后端接口、持久化或召唤流程。
- 不新增场景、分类或“综合”排序。
- 不修改左侧导航、“我的专家”管理卡片或其他页面卡片。
- 卡片点击继续打开详情，召唤按钮继续直接召唤；搜索、分类、排序和专家/专家团切换保持不变。

## 验收标准

- 专家网格使用 288px 最小列宽和 12px 间距，按内容宽度自然形成 4/3/2/1 列。
- 专家卡片最小高度 154px、圆角 16px，默认使用技能卡片同款浅色主题表面；悬浮/聚焦只即时显示主题色边框，不切换背景。
- 章节标题与专家/专家团切换使用 20px/600/28px；卡片名称按用户视觉偏好使用 14px/600/20px，副标题使用 11px/400/16px，避免通用规则意外放大。
- Windows 专家页局部使用 WorkBuddy 的 `Segoe WPC`/`Segoe UI`/`Microsoft YaHei` 字体栈；精选场景专家名称按用户视觉偏好使用 14px/600/20px 主文字色，其他平台和全局字体不变。
- 顶部专家/技能/连接器导航的已选按钮在悬浮时保持主题色，灰色悬浮反馈只用于未选按钮。
- 顶部导航与专家主体共用同一画布，不设置独立背景或水平分隔线；现有高度、内边距、搜索和响应式布局保持不变。
- 外层卡片不使用悬浮位移、缩放、阴影、滤镜、透明度动画或 `will-change`。
- 精确指针设备的召唤按钮只在悬浮/聚焦时显示；触屏/粗指针设备不依赖 hover。
- 精选场景为紧凑横向卡片，整卡无悬浮变化，内部专家行保留小面积反馈。
- 专家目录交互测试和前端构建通过，用户完成应用视觉验收。
