# 任务 002：统一能力工作区排版

## 目标与依据

让技能页和连接器页复用专家页的外层画布与间距，消除三页切换时顶部背景、分隔线和内容起点跳变；并按确认范围把连接器目录和已新增 MCP 外层卡片统一为技能卡片同款轻量表面。Codegraph 与工作树源码确认三页共享 `.capability-workspace-shell`，卡片差异也可在公共 CSS 收敛，无需修改业务组件。

## 允许范围

- `desktop/frontend/src/styles/features.css` 中能力工作区外层画布、导航和主体内边距。
- `workbuddy-primary-navigation.test.ts` 的布局契约。
- 本任务回执、计划和进度文档。

## 禁止范围与保留行为

- 不修改 `CapabilitiesPanel.tsx`、专家目录组件结构或数据流。
- 不改变技能搜索、管理、插入会话和启用开关。
- 不改变连接器添加、配置、选择、测试和开关。
- 不改变技能卡片、连接器卡片内部内容和滚动归属；允许统一连接器外层卡片的表面、边框、阴影和过渡。

## 验收标准

- 三页共用 `var(--chat-bg)` 画布。
- 技能/连接器桌面顶部与专家页一致为 96px，保留 14px 24px 内边距，无独立背景和下分隔线。
- 技能/连接器主体全宽，桌面为 20px 24px、窄屏为 18px 16px 内边距。
- 技能页搜索框与下方技能卡片使用相同的主题背景公式。
- 连接器目录和已新增 MCP 卡片使用技能卡片同款浅色主题表面；普通悬浮/聚焦仅显示主题色边框，无阴影或动画。
- 连接器已用于任务的绿色状态和配置错误的红色状态不被普通悬浮规则覆盖。
- 专家页现有布局和三页业务交互保持不变。
- 导航契约、专家渲染契约和前端构建通过。
