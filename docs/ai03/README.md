## 生命周期

1. `plan.md` 记录已确认的范围与方案。
2. `tasks/` 记录可独立实施和验收的任务合同。
3. `progress.md` 只保存可复核的阶段证据，并明确下一门禁。
4. 完成后把仍然有效的产品行为写回稳定指南或架构文档，再把整组材料迁入 `docs/archive/`。
